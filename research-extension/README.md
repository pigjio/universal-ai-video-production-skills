# Research Extension（独立研究扩展层）

## 默认关闭

本包默认运行 **production（生产层）**。research-extension 不会因创建项目、保存作品、启用 provenance、上传生产素材或确认阶段而自动开启。研究数据同意默认 `denied`。

## 单独启用条件

只有同时满足以下条件才可启用：

1. 在 `AUTHORIZATIONS.md` 中对 `AUTH-RESEARCH` 有独立、明确、可定位的同意记录；
2. 说明研究目的、数据范围、处理方式、保存期限、共享对象（如有）和撤回方式；
3. 用户同意的范围与即将执行的动作一致；
4. 与上传、付费、公开发布等其他动作分别取得授权。

缺少任一项时保持关闭。用户撤回后停止未来收集和处理，并按约定处理已收集数据；保留必要的撤回审计记录，但不得扩大用途。

## 单向隔离规则

- production 的 confirmed 状态只由 production 阶段确认协议决定。
- 研究层可读取经授权的数据副本、生成研究观察或统计结果，但**不得反向修改、覆盖、降级或升级 production 的确认状态、成果文件、项目索引或用户决定**。
- 研究结论不是生产事实，也不是人工确认；如希望用于生产，应作为新的 candidate 提交用户审阅，经过正常阶段确认后创建新的 production 版本。
- 研究文件与生产成果分开存放、单独标识，避免索引混淆。

## 最小化原则

只处理实现已说明研究目的所需的数据；不知道是否在授权范围内时不处理，并先请求单独确认。保存作品不等于同意研究、训练、评测或发表。
