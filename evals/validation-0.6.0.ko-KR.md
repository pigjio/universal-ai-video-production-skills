# 0.6.0 창작 협업 강화 및 검증 보고서

[중국어 안내](validation-0.6.0.md)｜[한국어 안내](validation-0.6.0.ko-KR.md)

## 목표

0.6.0은 이론을 먼저 배울 필요가 없는 학생과 일반 창작자를 위해 **만족할 때까지 논의한 시나리오 → 시나리오 근거가 있는 스토리보드 → 바로 복사할 수 있는 Seedance / Jimeng 프롬프트** 흐름을 강화합니다. 전문 지식은 내부의 선택, 진단, 품질 경계에 사용합니다.

## 주요 변경 사항

- 현재 문제에 따라 하나의 주 도구를 선택하고 부적합 조건을 밝히는 교차 서적 시나리오 이론 선택표를 추가했습니다.
- 제한된 범위를 완전한 장르 역사처럼 표현하지 않는 장르 관습 패키지를 추가했습니다.
- 확정된 내용과 영향받지 않은 내용을 보호하는 일곱 가지 모호한 피드백 부분 수정 사례를 새로 작성했습니다.
- ELS, LS, WS, MS, MCU, CU, ECU와 객관, 주관, POV, OTS를 다루는 숏 언어표를 추가하고 각 숏이 시나리오 근거를 갖도록 했습니다.
- Seedance 결과물 순서와 목표, 소재, 시작, 공간, 촬영, 시간축, 물리, 음향, 끝, 금지의 10개 항목을 추가했습니다.
- 중국어와 한국어 안내에서 세 가지 최종 결과를 동일하게 설명합니다.

## 검증 방법과 결과

배포 전에 Windows 환경에서 다음 검사를 실행했습니다.

```powershell
py -3 evals/check_creative_chain_0_6_0.py .
py -3 evals/check_korean_support.py .
py -3 evals/check_novice_runs.py
py -3 evals/validate_package.py .
```

결과:

- 창작 흐름 규칙 검사: 23/23 통과.
- 한국어 지원 회귀: 52/52 통과. 기존 `korean-natural-language-0.5.1` 사례 모음을 회귀 기준선으로 재사용했습니다.
- 초보자 동작 회귀: 11/11 통과. 기존 `novice-0.5.0` 사례 모음을 회귀 기준선으로 재사용했습니다.
- 패키지 정적 검증: Skill 10개, reference 94개, schema 레코드 34개 통과, 오류 0개, 경고 0개.

본 보고서는 결정론적 콘텐츠, 라우팅, 한중 일치, 버전, 비공개 경로, 기존 회귀 검사만 로컬 테스트라고 부릅니다. Seedance 호출, 소재 업로드, 실제 영상 생성·관찰, 외부 학생 인수 테스트는 수행하지 않으므로 플랫폼 생성 품질, 성공률 또는 예술적 만족도를 증명하지 않습니다.

대표 입력 사양은 `creative-chain-cases-0.6.0.json`에 있습니다. 이 사양은 규칙 범위를 확인하며 독립 모델 벤치마크나 실제 사용자 연구를 뜻하지 않습니다.

## 출처 및 저작권 경계

새 규칙은 로컬 증류 결과를 다시 구성한 것입니다. 공개 패키지에는 원본 서적, 비공개 경로, 긴 원문 인용이 포함되지 않습니다. 선택표, 표, 사례는 공개 Skill의 실행 목표에 맞게 새로 작성했으며 출처 경계는 각 Skill의 `references/source-map.md`에 기록했습니다.
