# 0.7.0: 연기·사운드·생성 위험·단계 간 추적

[中文报告](validation-0.7.0.md)｜[한국어 보고서](validation-0.7.0.ko-KR.md)

상태: 0.7.0 배포 검증 기록. 기준은 d85ca8acbadc61db7678c3da39e0d228201046b4입니다. 플러그인과 10개 Skill 버전은 0.7.0입니다. 태그 배포 후 main의 Marketplace를 전환합니다. Git 태그와 GitHub Release 페이지는 서로 다릅니다.

## 학생에게 달라지는 점

학생은 설명·비교·거절·확정만 하면 됩니다. 용어 학습, 표 작성, Skill 선택이 필요하지 않습니다. 하나의 Plugin과 10개 Skill 구성을 유지합니다.

| 보강 | 자연어 요청 예 | 내부 처리 |
|---|---|---|
| 연기와 신체 행동 | “슬프다는 설명 대신 행동으로 보여 주세요.” | 자극·목표·전략·행동, 숏에서 읽히는 증거, 프롬프트의 행동 순서 |
| 사운드와 립싱크 | “이 대사는 듣는 사람을 보여 주세요.” | 정확한 대사, 화자·청자·보이는 입, 소리의 시작·끝, 생성/후반 작업 분기 |
| 생성 위험 | “이 동작이 어색해요. 다른 촬영 방법은요?” | 위험 가설·근거 등급·대안의 서사적 대가·별도 승인 후 최소 실험 |
| 의도 추적 | “두 번째 숏만 바꿔 주세요.” | 의도·숏·요청 연결, 수정/재검토/보존 구분, 보호 조건 충돌 처리 |

조건부 참고 문서 4개를 추가하고 핵심 Skill 6개에 규칙을 연결했습니다. 나머지 4개는 패키지 버전만 통일했습니다. 공통 프로토콜, 고정 산출물 파일명, 확정·저장 권한은 유지됩니다. 중국어/한국어 README·개요·사용 설명서를 함께 갱신했습니다. 새 내부 참고 문서는 Agent용 중국어 방법 자료이며 학생이 읽을 의무는 없습니다.

## 출처와 한계

기존 도서 증류 자료의 관련 부분을 읽고 실행 규칙과 새 사례로 재구성했습니다. 도서 전체, 개인 경로, Hermes 원본 Skill, 프로젝트 자산을 복사하지 않았습니다.

- Dialogue: 언어 행동·서브텍스트·의도·반응. 원 방법론 요약에 NEEDS_REVIEW 표시가 있어 원서 전면 검증을 의미하지 않습니다.
- Film Directing Shot by Shot: 커버리지·동작 연결·대화 배치·화면 밖 소리·편집 연결.
- Directing the Story: 관객의 인과 이해·예비/행동/반응/여파·결정 행동.
- 위험 지도·음향 계약·추적 필드·수정 절차는 패키지의 공학적 종합입니다. 완전한 연기 이론이나 전문 사운드 디자인/믹싱 서적을 모두 반영했다고 주장하지 않습니다.

## 신구 버전 텍스트 시험

1차에는 중국어 무대사 선택 장면, 한국어 서브텍스트와 청자 커버리지, 열쇠를 받는 손의 부분 수정 등 3개 과제를 신구 버전에서 각각 한 번 실행했습니다. 버전별 별도 Agent가 세 과제를 순서대로 처리해 같은 버전 안의 맥락 이월 가능성이 있습니다. 여섯 번의 완전 독립 실험은 아닙니다. 채점 Agent는 실행 Agent와 다르지만 블라인드 평가는 아닙니다. 과제 실행 후 판단 항목을 추가했고 실행 Agent는 항목을 읽지 않았습니다.

원 출력·채점·재실행은 저장소 밖 로컬 검토 작업 공간에 보존했습니다. 컴퓨터 경로가 있는 실행 기록은 공개 패키지에 넣지 않습니다. 시간·token은 신뢰할 수 있게 기록되지 않아 0이나 문자 수를 측정값으로 제시하지 않습니다.

1차에서 기존 항목 밖의 연결 모호성을 발견했습니다. 한국어 수정안이 청자의 시선 도착을 앞 숏 끝으로 옮겼는데 다음 숏에서 다시 관찰을 시작할 수 있었습니다. 공통 프롬프트와 의도 추적 규칙에 “앞 숏 끝과 다음 숏 시작을 비교하고 완료된 행동을 반복하지 말고 상태를 이어받기”를 추가했습니다. 원 출력을 고치지 않았으며 한국어 과제만 신구 버전으로 다시 실행하고 행동 연결 항목을 추가했습니다.

1차 고정 항목은 신버전 15/15, 구버전 14/15입니다. 과제별로 신버전은 5/5·5/5·5/5, 구버전은 5/5·4/5·5/5입니다. 차이는 구버전 한국어 수정 프롬프트 코드 블록에 원 대사가 없고 블록 밖 음향 계획에만 있다는 점입니다. 나머지 14항목은 양쪽 모두 통과해 버전 가치를 구분하지 않습니다. 신버전의 시선 연결 모호성은 이 15항목 밖에 있어 전항목 통과로 숨길 수 없습니다.

전체 실행 transcript 없이 실행 노트만 있어 도구 호출·읽기 격리의 과정 주장은 독립 검증되지 않았습니다. 표시되는 분산은 서로 다른 과제의 차이이지 반복 실행 안정성이 아닙니다. 재실행 결과는 별도로 기록하며 1차 점수를 덮어쓰지 않습니다. 이야기 리듬·연기의 자연스러움·프롬프트 사용성에 대한 사용자 의견은 아직 수집하지 않았습니다.

### 한국어 독립 재실행과 제한된 수정

2차는 한국어 과제만 별도 두 실행 Agent로 다시 수행하고 여섯 번째 “인접 프롬프트의 핵심 끝/시작 상태 계승” 항목을 추가했습니다. 신구 모두 5/6이지만 실패 항목은 다릅니다. 신버전은 시선 반복 모호성을 해결했으나 S02-B 복사 블록에 화면 밖에서 손이 멈추는 동작과 끝 상태가 빠졌습니다. 블록 밖 설명과 S03 시작에는 해당 정보가 있습니다. 구버전은 정확한 대사가 여전히 블록 밖에만 있지만 동작 연결은 명확합니다. 새로운 기준이므로 두 차수의 전체 통과율을 동일 척도로 직접 비교할 수 없습니다.

이에 핵심 동작을 같은 장면의 화면 밖 사건으로 옮겨도 현재 요청 안에 동작과 끝 상태를 쓰고, 이를 보여 주려고 카메라가 임의로 돌아가지 않도록 하는 일반 규칙을 추가했습니다. “항상 손을 찍기”가 아니라 커버리지 수정 중 다음 상태를 잃지 않기 위한 규칙입니다.

3차는 2차 신버전 응답에 알려진 피드백을 반영하는 최소 수정 검사이며 6/6을 통과했습니다. 원문 비교로 S02-B의 화면 밖 동작·끝 상태와 “화면의 주요 변화” 문구만 수정했고 나머지 시나리오·숏·대사·미확정 상태는 보존했음을 확인했습니다. 새로운 독립 전체 실험으로 간주하지 않으며 5/6 결과를 지우지 않습니다. 최종 규칙 추가 후 세 과제 전체를 다시 독립 실행하지 않았으므로 일반적인 안정적 개선을 주장하지 않습니다.

## 미검증 범위와 출시 조건

- Seedance/Jimeng 호출·생성·업로드·유료 실행이 없습니다. 음성·립싱크·참고 입력·길이는 실제 모델과 제품 입구에서 별도로 확인해야 합니다.
- 실제 학생 시험이나 통계적 유의성 증거는 없습니다. 소수 과제의 통과가 일반적인 우월성을 증명하지 않습니다.
- Hermes 원본·설치된 Skills·원 지식베이스를 수정하지 않았으며 기존 v0.6.0 tag도 유지했습니다.
- 사용자가 업로드와 버전 갱신을 승인했습니다. 최종 회귀와 파일 해시 확인 후 커밋 및 새 버전을 만들고, 새 tag가 실제로 존재한 후 main의 Marketplace를 전환합니다.

### 프롬프트 템플릿 국소 수정 재검사

독립적인 ‘숏 02’ 블록의 중복 S01을 S02로 수정하고, 두 번째 독립 블록과 단일 숏 기본 템플릿에 스타일·장면·인물 정체성·실제 참고 자료의 역할을 보완했습니다. 숏별 필드는 유지하며 삭제한 다섯 요청 공통 머리글은 복원하지 않았고, 마지막 줄은 여전히 “无背景音乐”입니다. 번호의 비어 있지 않음·유일성, 제목 일치, 독립 문맥, 템플릿 예상 순서 및 잘못된 예제 검사를 추가해 규칙 검사는 20/20, 다른 회귀 검사를 포함하면 총 106항목입니다. 주 에이전트는 메모리에서 빈 번호·중복 번호·제목 불일치가 거부되고 유효한 비연속 번호는 허용되는 것도 확인했습니다. 이번 검증은 템플릿 수정과 정적 회귀에 한정되며, 독립적인 중한 창작 출력은 다시 실행하지 않았습니다. 이전 텍스트 평가 점수를 바꾸거나 실제 영상 생성 통과를 주장하지 않습니다.
