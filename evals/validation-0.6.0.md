# 0.6.0 创作协作增强与验证报告

[中文说明](validation-0.6.0.md)｜[한국어 안내](validation-0.6.0.ko-KR.md)

## 目标

0.6.0 面向不需要学习理论的学生与普通创作者，强化“讨论到满意的剧本 → 有剧本依据的分镜 → 可直接复制的 Seedance / 即梦提示词”链路。专业知识只在后台提供选型、诊断和质量边界。

## 主要变化

- 新增跨书剧作理论选择矩阵，要求按当前问题选一套主工具并说明不适用条件。
- 新增有来源边界的类型惯例包，不把有限覆盖写成完整类型史。
- 新增七类模糊反馈的原创局部修订案例，保护已确认和未受影响内容。
- 新增 ELS、LS、WS、MS、MCU、CU、ECU 及客观、主观、POV、OTS 的镜头语言表，并要求分镜追溯剧本依据。
- 新增面向创作者的 Seedance 交付顺序和目标、资产、起点、空间、摄影、时间轴、物理、声音、终点、禁止十项骨架。
- 中文与韩文入口同步说明三项最终成果。

## 验证方法与结果

发布前在 Windows 环境执行：

```powershell
py -3 evals/check_creative_chain_0_6_0.py .
py -3 evals/check_korean_support.py .
py -3 evals/check_novice_runs.py
py -3 evals/validate_package.py .
```

结果：

- 创作链规则检查：23/23 通过。
- 韩文支持回归：52/52 通过；沿用 `korean-natural-language-0.5.1` 历史案例集作为回归基线。
- 新手行为回归：11/11 通过；沿用 `novice-0.5.0` 历史案例集作为回归基线。
- 包静态验证：10 个 Skill、94 个 reference、34 条 schema 记录通过，0 个错误、0 个警告。

本报告只把确定性内容、路由、中韩一致性、版本、隐私路径和既有回归检查称为本地测试；没有调用 Seedance，没有上传素材，没有生成或观看真实视频，也没有进行外部学生验收，因此不证明平台生成质量、成功率或艺术满意度。

代表性输入规格见 `creative-chain-cases-0.6.0.json`。它们用于确认规则覆盖，不等同独立模型基准或真实用户研究。

## 来源与版权边界

新增规则来自本地蒸馏成果的重新组织。公开包不包含原始书籍、私有路径或长段原文；矩阵、表格和案例均按公开 Skill 的操作目标重新编写。来源边界记录在各 Skill 的 `references/source-map.md`。
