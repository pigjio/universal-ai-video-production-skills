# 0.5.1 韩文自然语言增强测试报告

[中文说明](korean-validation-0.5.1.md)｜[한국어 안내](korean-validation-0.5.1.ko-KR.md)

测试日期：2026-09-10

## 目标

验证韩文用户无需知道 Skill 名即可表达创作需求，并确保语言切换不改变新手引导、阶段状态、证据标准和授权边界。

## 覆盖范围

- 10 个 Skill 各有一个韩文自然语言发现样例；
- “不知道”、积极反馈、确认但不保存、确认并保存但不上传、拒绝研究、跨会话恢复 6 类韩文语义；
- 共享新手协议与 10 个 Skill 内置副本的一致性；
- 中文原有 11 项新手流程回归；
- Plugin 清单、版本、引用、schema、链接、隐私和发布清单。

## 自动化检查

运行：

```bash
python evals/check_korean_support.py .
python evals/check_novice_runs.py .
python evals/validate_package.py .
```

结果：

- `check_korean_support.py`：52/52 通过；
- `check_novice_runs.py`：11/11 通过，原有中文新手流程未回归；
- `validate_package.py`：10 个 Skill、88 个引用资源、34 条 schema 记录通过，0 错误、0 警告；
- Codex Plugin validator：通过。

韩文发现检查证明每个 Skill 的公开描述包含对应韩文自然语言入口；它与真实模型烟雾测试结合使用，但不代表所有模型和所有表达方式都已穷举验证。

## 真实模型烟雾测试

- 环境：Codex CLI `0.153.4`，模型 `gpt-5.6-sol`，reasoning effort `medium`；
- 方式：在独立、临时、只读会话中读取本仓库 Skill 描述、共享协议与韩文案例，以结构化 JSON 返回分类；
- 路由：10/10 通过；
- 行为：6/6 通过；
- 副作用：未写入仓库，未上传、生成、付费、发布或执行研究。

该测试验证了当前 Codex 环境下这些具体韩文表达的路由与授权语义，不覆盖所有韩文变体、其他模型版本或所有平台入口。

## 结论

0.5.1 的 10 个韩文自然语言路由案例和 6 个关键授权行为均通过静态检查与真实模型烟雾测试；中文原有测试保持通过。可以发布为韩文增强补丁版本，但不应表述为“任何韩文说法、任何模型都绝对得到完全相同结果”。
