# 0.5.1 한국어 자연어 지원 강화 테스트 보고서

[중국어 안내](korean-validation-0.5.1.md)｜[한국어 안내](korean-validation-0.5.1.ko-KR.md)

테스트 날짜: 2026-09-10

## 목표

한국어 사용자가 Skill 이름을 몰라도 창작 요구를 표현할 수 있는지 검증하고, 언어를 전환해도 초보자 안내, 단계 상태, 증거 기준, 권한 경계가 바뀌지 않는지 확인합니다.

## 검증 범위

- 10개 Skill 각각에 한국어 자연어 발견 예시 1개
- “모르겠어요”, 긍정적 피드백, 확정하되 저장하지 않기, 확정 후 저장하되 업로드하지 않기, 연구 거절, 세션 간 복구라는 6가지 한국어 의미
- 공통 초보자 프로토콜과 10개 Skill 내장 복사본의 일치 여부
- 기존 중국어 초보자 흐름 11개 회귀 검사
- Plugin 매니페스트, 버전, 참조, schema, 링크, 개인정보, 배포 목록

## 자동 검사

실행 명령:

```bash
python evals/check_korean_support.py .
python evals/check_novice_runs.py .
python evals/validate_package.py .
```

결과:

- `check_korean_support.py`: 52/52 통과
- `check_novice_runs.py`: 11/11 통과, 기존 중국어 초보자 흐름 회귀 없음
- `validate_package.py`: 10개 Skill, 88개 참조 리소스, 34개 schema 기록 통과, 오류 0, 경고 0
- Codex Plugin validator: 통과

한국어 발견 검사는 각 Skill의 공개 설명에 해당 한국어 자연어 진입점이 포함되어 있음을 증명합니다. 실제 모델 스모크 테스트와 함께 사용하지만, 모든 모델과 모든 표현 방식을 빠짐없이 검증했다는 뜻은 아닙니다.

## 실제 모델 스모크 테스트

- 환경: Codex CLI `0.153.4`, 모델 `gpt-5.6-sol`, reasoning effort `medium`
- 방식: 독립적이고 임시적인 읽기 전용 세션에서 이 저장소의 Skill 설명, 공통 프로토콜, 한국어 사례를 읽고 구조화된 JSON으로 분류 결과 반환
- 라우팅: 10/10 통과
- 동작: 6/6 통과
- 부작용: 저장소 쓰기 없음, 업로드·생성·결제·게시·연구 실행 없음

이 테스트는 현재 Codex 환경에서 시험한 구체적인 한국어 표현의 라우팅과 권한 의미를 검증합니다. 모든 한국어 변형, 다른 모델 버전, 모든 플랫폼 진입점을 포괄하지는 않습니다.

## 결론

0.5.1의 한국어 자연어 라우팅 사례 10개와 핵심 권한 동작 6개는 정적 검사와 실제 모델 스모크 테스트를 모두 통과했습니다. 기존 중국어 테스트도 계속 통과했습니다. 한국어 지원 강화 패치 버전으로 배포할 수 있지만 “모든 한국어 표현과 모든 모델에서 반드시 완전히 동일한 결과를 낸다”고 표현해서는 안 됩니다.
