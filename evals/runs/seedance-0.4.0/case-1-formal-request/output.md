## 4. 必要接口与放行闸门

### 4.1 素材绑定接口

执行者必须在实际 Seedance 入口中把代码块内 `@参考A`、`@参考B` 分别绑定到用户所说的两个已上传资源，并记录真实资源句柄、附件序号或平台回执。本稿只能确认“用户声明已上传”，不能确认平台当前会话仍可访问，也不能虚构句柄。

### 4.2 请求内状态接口

- `SHOT-01 → SHOT-02`：角色A已在工作台前停稳；金属环仍完整静置桌面；拿取尚未开始。
- `SHOT-02 → SHOT-03`：角色A右手已稳定持有唯一完整金属环；金属环已离开桌面；放置尚未开始。
- 后镜必须建立既成状态并继续，禁止重演前镜已完成动作。

### 4.3 跨请求接口

当前 `next_segment_interface: null`，因为方案只登记一个生成请求，且尚无真实生成尾帧。若能力核验要求拆请求，需另版登记接口来源；优先依据实际条件选择文字重建、独立重启、真实合格尾帧或已验证平台上下文，不能仅写“沿用上一段”。

### 4.4 提交前能力接口

提交前必须取得带核验日期、具体模型、产品入口和模式的当前能力事实，至少包括：

1. 是否支持一个请求内生成并切分三镜；
2. 可选请求窗口与导演目标时长如何匹配；
3. 支持的画幅；
4. 参考素材类型、数量、绑定语法与当前资源可访问性；
