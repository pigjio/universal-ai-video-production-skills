# Provenance（来源与证据层）

## 定位

本包默认只启用 **production（生产层）**。provenance 是按需使用的来源与证据记录层，适合在需要追踪素材来源、许可、引用、生成参数、提交凭据或审查链时启用；普通创作不强制增加负担。

## 使用原则

- 只记录可核验事实；不知道就写 unknown，不补造来源、许可或提交凭据。
- 将来源记录与具体 `artifact_id`、`version` 和文件路径关联，不写含糊的“最新版”。
- 区分“文件存在、已读取、已上传、已提交、已生成、已人工接受”，这些不是同一证据。
- provenance 可为 production 提供证据，但不能仅凭证据记录代替用户的阶段确认。
- 来源或许可发生变化时，保留历史并触发受影响成果复核，不覆盖旧记录。
- 不记录与当前工作无关的个人信息或敏感信息。

## 与研究层的边界

provenance 不等于 research-extension。为生产交接记录素材来源，不自动构成研究数据同意。研究用途仍需 `AUTHORIZATIONS.md` 中独立、明确且未撤销的 `AUTH-RESEARCH`。
