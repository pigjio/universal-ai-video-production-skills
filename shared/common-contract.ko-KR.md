# 협업 및 저장 원칙

- 사용자가 현재 쓰는 언어로 대화합니다. 파일 이름과 숏 ID는 언어를 바꾸어도 유지합니다.
- 먼저 필요한 초안이나 수정을 제시합니다. 모르는 항목은 미정으로 표시하며 사실로 만들지 않습니다.
- 일부에 대한 긍정적 반응은 전체 단계의 확정이 아닙니다. 요청된 부분과 필요한 연관 부분만 수정하고 충돌이 있으면 알립니다.
- 한 번에 꼭 필요한 질문은 하나만 합니다. 다음 작업을 이미 명시했다면 같은 승인을 반복해서 묻지 않습니다.
- 단계 건너뛰기, 토론만 하기, 저장하지 않기가 가능합니다. 무인물·비서사 작품에 인물이나 갈등을 강요하지 않습니다.
- 완성된 단계 초안의 논의가 정리되면 “확정 후 저장 / 확정하되 저장하지 않음 / 계속 수정”을 한 번에 제안할 수 있습니다. 기존의 유효한 저장 동의는 존중합니다.
- 저장할 위치와 허락을 확인하고 새 버전으로 저장합니다. 요약이 아닌 전체 결과를 저장합니다. 덮어쓰기, 삭제, 업로드, 생성, 비용 지출, 공개, 연구 활용은 각각 해당하는 동의가 필요합니다. 연구 활용에는 기본적으로 동의하지 않은 상태입니다.
- 처음 저장할 때 필요한 PROJECT_BRIEF.md, AUTHORIZATIONS.md, PROJECT_INDEX.md, SESSION_HANDOFF.md, DECISIONS.md를 templates에서 만들되 기존 파일은 덮어쓰지 않습니다.
- 단계 파일의 고정 이름은 项目简报_vNNN.md, 剧本大纲_vNNN.md, 剧本_vNNN.md, 世界观_vNNN.md, 角色设计_名称_vNNN.md, 场景设计_名称_vNNN.md, 分镜_vNNN.md, 视频提示词_vNNN.md, 生成计划_vNNN.md, 生成评审_vNNN.md입니다. 안전한 이름을 사용하고 기존 번호를 확인하여 증가시킵니다. 한국어 본문에도 같은 파일 이름 규칙을 적용합니다.
- 저장 후 파일을 다시 읽고 PROJECT_INDEX.md와 SESSION_HANDOFF.md에 실제 경로, 상태, 다음 작업을 갱신합니다. 실패하면 완료했다고 말하지 않습니다.
- 재개할 때 프로젝트 개요, 동의, 색인과 실제 결과 파일을 확인합니다. 누락되거나 충돌하면 확정된 것으로 취급하지 않습니다.
- 실제로 확인한 자료만 증거로 사용합니다. 영상을 보지 않았다면 동작, 소리, 타임코드를 검토했다고 말하지 않습니다.
- 프롬프트 완성은 생성 성공이 아닙니다. 길이, 참고 자료 수, 음성 및 립싱크 기능은 현재 플랫폼에서 확인합니다.
