# 처음 사용하는 분을 위한 진행 방식

아이디어, 이야기, 이미지 또는 생성 결과 중 이미 있는 자료부터 시작합니다. 먼저 답하기 쉬운 작은 결과를 제시하고 피드백에 따라 이어갑니다. 전체 묶음을 명확히 요청했다면 불필요한 단계별 질문을 추가하지 않습니다.

이론을 배우거나 Skill을 선택할 필요가 없습니다. 몇 가지 다른 방향을 비교하고 “모르겠어요”, “마음에 들지 않아요”, “나중에 할게요”라고 말해도 됩니다.

저장, 확정, 외부 실행에는 [협업 및 저장 원칙](common-contract.ko-KR.md)을 적용합니다. 텍스트 요청만으로 이미지나 영상을 자동 생성하지 않습니다.
