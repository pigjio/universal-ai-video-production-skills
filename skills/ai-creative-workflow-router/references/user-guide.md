# 通用 AI 影像制作 Skills 使用说明

[한국어](user-guide.ko-KR.md)

## 从现有材料开始

你可以从模糊想法、故事／剧本、图片或生成结果开始。不需要先填写长表，也不用选择技能。告诉助手“先给我一个草案”“这里不喜欢”“再简洁些”即可。

## 剧本与设计

先讨论大纲，再按需要完善详细剧本；也可直接修改现有稿件。大纲或详细剧本讨论收口后，助手会询问是否整理角色、场景清单和 Midjourney 提示词，或继续修改。只要清单、只做其中一种、暂时不做都可以。

角色提示词默认四个简短段落：身份体型、面部、服装道具姿态、配色与画面。不会自动加 3D 风格。场景提示词更轻量，以剧本地点、关键物件和情绪为主，可以使用“电影级构图”，不强加大量限制。

## 分镜与视频提示词

文字分镜依据当前剧本，讨论镜头内容、景别、动作、时长和衔接。随后可交付 Seedance 提示词；每段带完整字段，末行固定为“无背景音乐”。这不禁止对白、音效和环境声。

提示词不代表平台一定支持或一定成功。实际生成前按当前平台确认素材、时长及声音能力；生成后带上实际图片／视频和具体问题再讨论修改。

## 保存与恢复

可以只聊天不保存。阶段完成时可选择确认并保存、确认但不保存或继续修改。保存需要目录与授权，默认保留旧版、另存完整新版本；恢复时依据项目记录与实际文件。

上传、生成、付费、公开或研究使用不包含在普通保存同意中。
