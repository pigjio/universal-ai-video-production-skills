# AI 影像世界观

## 新手引导与阶段成果落盘

本阶段开始时显式读取 `references/novice-guidance-protocol.md`；涉及正式状态、授权、版本、证据或交接时同时读取 `references/common-contract.md`。默认采用**新手模式**，用户可切换协作或专业模式；切换只改变讲解密度，不删减下文的规则、空间与一致性判断。

阶段落盘必须保存完整正文，并在写后回读通过后更新 `PROJECT_INDEX.md` 与 `SESSION_HANDOFF.md`；这三个文件及其状态必须相互一致。

- 每轮只推进一个小目标，最多提出一个阻断问题；其他未知写成可替换假设。首轮先给一条可运行规则、一段由规则产生的日常或一个具体一致性判断，再问至多一个问题，不能只发设定问卷。用户可回答“不知道”，随后采用清楚标注的推荐假设继续。
- “推荐这个”“不错”“可以”“继续”是偏好或探索指令，不是阶段确认。仅有“阶段完成”“按此定稿”或同等明确表述才构成人工确认；规则、历史、Canon 与例外等关键裁决不得自动代批。
- 阶段稿成熟时先给可独立阅读的完整设定正文。项目已有一次性“阶段确认后保存”授权时，明确确认后直接写新版本；否则将确认与保存合并成一个问题，主动提供“确认并保存为新的 Markdown 版本 / 确认但暂不保存 / 继续修改”三种自然选择。用户选择保存且目录明确后，自动创建缺失的项目基础记录文件，不要求新手手工复制或填写内部字段。阶段主文件固定为 `世界观设定_vNNN.md`：写前扫描同名文件，以最大三位版本号加一，首次 `v001`，不覆盖；正文完整保存约定范围内的基准、规则机制/边界/证据、已定/暂定/禁用项和下游接口，不用百科摘要或修改列表代替。
- 写后回读，再更新 `PROJECT_INDEX.md` 的当前版本/状态/链接和 `SESSION_HANDOFF.md` 的人工裁决、冲突/未决项、下一步，并回读关键更新。任何一步失败均报告实际状态，不得报成功；保存目录未知时只补问该阻断项。
- 保存不等于阶段确认、Canon/生产批准或 research 同意，不授权联网、采集、上传、付费、生成或发布；正式交接与依赖变更继续依 `references/common-contract.md`。

## 1. 边界与公共协议

把故事、视觉概念或现实题材的必要设定转成影响行动、空间、资产、声音和生成结果的规则系统。不是百科；风格不自动等于规则。现实项目可只建当前视觉、空间、时间约束表，不为短片强写长篇世界史。

进入阶段、交付和上游改版时加载 `references/common-contract.md`。用户只讨论则只答复；授权落盘时确认项目目录、保留版本，不静默覆盖批准稿。缺工具交待办，不虚构生成结果。正文为通用默认，reference 为条件方法；项目可授权改风格/格式/时长，不可覆盖真实性和授权。

### 讨论与工作深度

按意图选择讨论、探索草案、正式成稿、生产交接/验证，不新增公共 YAML 字段。讨论直接判断或局部试写，未知可保留，不落盘、不强求公共头与生产闸门。探索可比较联动规则与生活候选，假设可替换，不等于正式 candidate；正式成稿只完整写用户指定范围，输入足够即写；交接/验证才执行完整公共协议与证据闸门。

循环为当前意图→具体判断/试写→必要的替代与代价→吸收反馈→只改受影响项。内部记已定、暂定、否决原因、开放项，不每轮输出固定表，不强迫收敛；AI 推测不能称受众反馈。转交接时读 `references/visual-state-and-handoff.md` 的分层方法。

正式记录与下游传递 creative_mode: narrative | perceptual | conceptual 与 subject_type: character-led | environment-led | object-led | abstract；自然讨论不为填字段中断回答。无人物 `character: null` 合法：
- narrative：规则→使用/受压→选择→后果→证据。
- perceptual：感知目标→材料/空间约束→光声运动/观看路径→可观察变化→完成判据。
- conceptual：命题→规则/对照操作→可观察差异→支持或反例及解释边界。

世界基准可以本来受损、黑白、断电、抽象；不自动改成“正常、完整、彩色”。没有人物不必造欲望、对手或社会冲突。

## 2. 输入与核心模型

判断任务：现实约束、局部地点、幻想机制、文化社会、历史、地图、视觉语言或一致性诊断。输入 payload 包含媒介/受众/形式/制作限制、核心或剧本动作/感知要求、角色（可 null）、已有事实、提案、禁用假设、当前版本和请求范围。

核心链：差异/基准→运行机制→边界与适用后果→空间/资产/声音证据→一致性→下游交接。社会关系仅适用时加入受益/受害分析。

已确认事实、待裁决候选、灵感材料分开；灵感是材料分类而非公共生命周期枚举。模型输出和生成图片不能自动进入 Canon。世界类型可为现实叠加、隐藏/平行或独立世界；入口/回归机制只在存在跨界时建立，不强加传送门。

## 3. 最小规则集

先回答与现实或项目基准相比最关键的差异，再追踪它对自然、资源、技术、日常、文化和空间的实际影响，不全量填百科。

内部规则卡 payload：规则ID、机制/来源、使用/触发条件、谁可操作（适用时）、边界/失败方式、代价或物理后果、受益/受害/排除者（社会适用时）、人物选择或感知/概念操作、可见可听证据、禁止推断、未决项。

“神秘、古老、压抑”只在风格栏；要成为规则须说明改变什么可观察条件。能力应有限制、代价或后果；感知规则不必有道德代价。装饰合法，但不得暗中取得机制能力。

- 技术/魔法：能力→条件→限制→代价/后果，检查资源、维护、误用和失效。
- 社会：规范→执行者→获益/排除→违规后果，不把制度写成全体一致信仰。
- 自然：条件→材料/资源→物理/生态限制→适应行为或可观察效果。

规则至少服务选择/阻力、空间路径、资产、光声材料或概念对照之一；都没有则降为背景灵感/装饰，不为补作用滥加惩罚。

## 4. 母题权限与能力边界

花、水、线、风、晶体等重复元素先明确是装饰、指示器、载体还是源头；允许组合但逐项授权：
- 装饰只负责视觉重复，不能因画了花纹就解锁能力。
- 指示器显示其他系统状态，不改变系统。
- 载体传递/储存既有量，写容量、损耗、路径，不凭空产生。
- 源头确实产生量或状态，写来源条件、产出上限、代价与停止机制。

写“根本原因→指示/承载→日常用途”，危机和恢复尽量沿同链展示；日常用途不越权取代根因。特殊生物先选唯一个体/临时显形/生态现象/物种/文明，按项目需要，不默认扩成王国。需要具体权限表与反例测试时加载 `references/rules-costs-and-ethics.md`。

## 5. 基础设施与条件历史深度

按需求建立空间（边界、入口/出口、可达性、移动/观察规则）、时间（当前时点、周期、前史、变化来源）、社会（劳动、交换、照护、禁忌）、资源（来源、稀缺、维护、分配）、文化（语言、仪式、服饰、日常）、生态/技术（生物链、普及、故障）。无居民/抽象项目可标社会文化不适用。

历史深度不是由“梦境/模拟”标签决定。先选：独立演化历史；生成且无独立前史；生成但继承/模拟历史；未知。第二分支才约束不能从生活设施自动推导王朝/宗教史；第三分支可有遗迹，但区分实际过去与内置记忆。未知保留假设，不一刀切禁用古迹。加载 `references/culture-timeline-and-canon.md` 执行历史分支、文化推导和时间线案例。

地图记录入口出口、路径方向、门槛、遮挡与时间条件。社会叙事再标谁使用/被排除及关键选择；无人物标风、光、声音和观众视线传播。地点作为“第三角色”是比喻，不要求空间有欲望。加载 `references/spatial-and-environmental-evidence.md` 做拓扑、旅行时间和环境证据检查。

## 6. 环境叙事与视觉语言

从磨损、维修、物品分配、废弃设施、标识、障碍、声源、光周期与移动方式传达世界，不让说明对白承担全部。道具可为欲望对象、秘密载体、关系信物、阶层/前史证据、铺垫兑现、冲突工具、视觉母题或纯装饰；分别标职责。

形状/构图说明秩序、隔离或流动；材质/磨损说明使用、时间或既定基准；光色/能见度说明观察条件、危险或信息控制；声音说明空间、生活或异常。母题写权限、第一次建立、后续观看/行动功能与结尾状态，不强要参与冲突。

只用**项目确认的基准状态**。母版可本来废墟黑白，派生仅指相对基准的变化（例如原有裂缝上新增积水，而不是“废墟”本身）。记录触发、前后状态、持续性与回退条件；不可逆或无需恢复的项目回退可不适用。加载 `references/visual-state-and-handoff.md` 执行状态账本和交接。

## 7. 世界与剧本/动作谱闭环

叙事检查规则如何改变选择，违反既定规则如何反馈，对手/主角如何使用不同策略；不要用规则替代动机。perceptual 检查材料/空间约束、观看路径与可观察完成状态，允许世界不被改变而观众认识改变。conceptual 检查对照操作是否受同一规则约束，不擅自赋予比喻真实因果。

当前故事实际使用的关键规则绑定场景/段落及必要可见可听证据；不要求所有后台事实出镜。不要靠加入新规则解释旧漏洞；要么澄清已有边界，要么提案改版并等待裁决。同一规则的不同解释或日常缺乏质感时，读 `references/culture-timeline-and-canon.md`：固定世界事实，改变知情与利益位置，试写不同动作；用同一早餐/维修的两种处境比较，不再扩写世界总史。谜团应保留到哪里也读该参考：机制因果要成立，不必解释全部来源。突然到场或幕后失效则读 `references/spatial-and-environmental-evidence.md` 的后台因果走查。

## 8. 一致性与异常处理

反查规则与角色能力、道具/服装、地图拓扑、时间、文化、对白、分镜和提示词：
- 无行动/感知/概念作用：补可观察约束或降级，不自动加代价。
- 事实/机制矛盾：定位层级和当前依据，提最小修复，不静默覆盖。
- 视觉读不出：补一个有职责的物件、动作、空间或声源，不堆装饰。
- 世界过大：保留当前段落所需和必要完整性感，其他候选归档。
- 生成结果引入设定：登记提案，不自动批准。
- 上游改版：直接和传递受影响角色/场景/分镜/Prompt 标 needs_recheck；旧批准留历史但不作当前门禁。无关依赖经影响检查保留并说明理由。

## 9. 公共输出模板

生产交接/验证及明确要求登记的正式世界记录附以下公共头；讨论、探索、仅供阅读的局部规则/日常草稿不强制 YAML。正式成稿按指定范围交完整内容，不自动扩为世界圣经；内部表作为 payload，不另发明状态。未齐输入保持草案，达到公共协议候选条件才登记 candidate。

```yaml
artifact_id: WORLD-window
version: v1
artifact_type: world
creative_mode: perceptual
subject_type: environment-led
lifecycle_status: draft
production_status: not_applicable
approval_level: none
upstream_versions: {}
confirmed_evidence: []
open_questions: []
recheck_trigger: []
next_action: request_review
```

payload：character（无人物为 null）；基准/差异；规则表（机制/边界/适用代价与社会关系/行动或感知后果/证据）；感知目标/材料空间约束/可观察变化/完成判据，或概念命题/对照/指标/反例；母题权限/禁用能力；历史分支/依据；空间图/路径/时间；文化资源推导（适用时）；视觉语言；派生状态；禁用/不可推断项；下游接口；真实人工裁决与未决项。

交剧本：规则和适用选择压力或感知/概念操作。交角色（存在时）：身份、能力、材料、身体适应、日常/禁忌。交场景：拓扑、功能、边界、维护、基准/派生。交分镜/Prompt：可见证据、传播路径、状态变化、不可推断项和参考职责。候选可供探索，不能当硬约束；方向批准不等于生产批准、实际生成或自动入 Canon。

## 10. 最终闸门与来源入口

- 核心差异与风格分开，范围可控。
- 模式贯通，character: null 合法；规则有模式对应作用，不强要人物代价。
- 母题权限明确，没有从指示器偷偷升级为源头。
- 历史深度由已确认前提决定，日常不自动证明古史，梦境也不自动排除古史。
- 空间可达/传播、时间、资源和文化互相成立；证据可见可听。
- 基准可本来受损黑白，只有相对变化才派生。
- 已确认/候选/灵感分离，下游可读，版本和复核边界完整。

来源审计时加载 `references/source-map.md`；源版 skill/reference 仅供识别迁移来源，不是执行依赖，不伪造原书页码或未核验锚点。
