# 主题、感知目标与核心图像

用于“只有氛围”“主题很大”或图像与主题互不相干。目标是可操作问题，不是先宣布正确答案。

## 步骤
1. 从材料卡引用具体细节，写它为何值得继续看；未知允许标假设。
2. 按模式选问题：叙事问价值如何在可选行动及后果中受检验；感知问注意力如何移动；概念问操作与对照显示什么差异。
3. 选择一个核心图像，让图像的材料、布局或变化承担问题。检验去掉说明文字后还能看到什么，不要求观众猜中唯一寓意。
4. 用同一材料做两个不同操作，比较结果而非堆主题标签。
5. 写开始状态、操作、结束状态和不能证明的内容；交给反证比较。

## 模式决策与具体小例
| 模式 | 可执行表达 | 不能强塞的表达 |
|---|---|---|
| narrative | 守门人可独自离开，也可留下维持通道；他在知道两者代价后选择留下。问题：责任是否必须由孤立牺牲完成？ | 用锁死出口证明“主动牺牲”；把问题先写成说教结论 |
| perceptual | 黑白破帘的影子先像平面纹理，气流使缝隙投影错开，观众认出墙面转角；看懂深度即结束 | 窗帘“克服恐惧”、画面必须恢复彩色 |
| conceptual | 相同缺口在不同侧光下被识别为不同轮廓；固定物体与背景，只变光向，比较轮廓辨识 | 因一个视觉隐喻宣称已证明人的普遍心理规律 |

核心图像记录示例：破帘裂口与墙角投影；职责是引导深度认知，不是传送门或能量来源；保持帘体破损，结尾只改变影子可读性。此例是提案，不构成实际测试或用户批准。

## 失败回退
- 若问题仍是“爱是什么”：缩到一个决定及后果，或一个材料操作与观看差异；不必提高赌注。
- 若图像漂亮但可随意替换：说明材料为什么影响操作；若没有影响，将其降为可换风格，不伪称核心母题。
- 若两个方向只有情绪词不同：固定材质，改变观看顺序、尺度或一个可用选项。
- 若用户不想固定主题：保存感知目标或开放问题，先做最小体验草案；不以主题未定阻止合法感知项目。

完成判据：别人能根据记录复述“什么在变化、为什么值得看、何时结束”，并知道哪些寓意或机制不能推断。
