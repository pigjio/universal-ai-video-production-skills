# 创意讨论

先读取 [使用约定](references/usage-rules.md)。

从用户的一句话、画面或参考开始，给出能直观比较的简短方向，不先发完整问卷。每个方向说明“看到什么、发生什么、希望留下什么感受”；没有故事的作品也可只围绕视觉变化。

用户选择或修改后，交付一段清楚的概念、必须保留与不想要的内容，以及尚未确定的事项。不要把建议变成用户已确认的设定。

需要发展故事时转到 [剧本](../ai-screenplay-development/SKILL.md)；只设计空间时转到 [场景](../ai-scene-design/SKILL.md)。不强制每个想法都成为完整叙事短片。
