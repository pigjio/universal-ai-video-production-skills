# 场景核心方法与构图诊断

场景设计把叙事或感知功能转为可行动、可观察空间。顺序：功能→拓扑→支撑面与尺度→透视/画幅/视觉动线→点线面与大形→明度结构→光源/投影/反射→材质/天气→环境证据。每个视觉选择都回答如何支持行动、注意力或世界规则。

## 决策步骤

1. 写第一眼焦点与第二眼关系，明确目标观看尺度和不可遮挡区域。
2. 画边界、入口、支撑面与地标连通关系，标摄影机位置；把屏幕左右与实际物理左右分开。
3. 用少量大明暗块检查缩略图。相近明度可合并次要形体，主焦点可用局部对比反转；不要把所有物体都描轮廓。
4. 锁光源方向、相对大小、投影、环境补光；材质高光依光源与观察方向，不能固定在物体最高点。雾色由光照和颗粒决定，不一律加蓝。
5. 在宽景读路线、中景读动作、近景读接触；失败定位到拓扑、构图、光色或材质再修。仅文字阶段列验证计划，不声称看过实际图。

## 构图症状—检查—修复表

| 症状 | 先检查 | 最小修复 | 回归标准 |
|---|---|---|---|
| 满屏细节不知看哪 | 主焦点是否有独占的对比/面积 | 合并背景明暗块、集中细节、释放负空间 | 缩略图先读到预定主体 |
| 角色/物体粘背景 | 轮廓交切、明度与切线 | 移小量机位或物体、局部明暗反转 | 关键轮廓和动作方向分离 |
| 空间像贴纸、太平 | 先核是否有意平面/有限空间，再查重叠、梯度与接触 | 意图成立则保留；需要纵深才加遮挡/尺度参照或修透视 | 目标空间类型成立，不强求深度排序；详见 spatial-intent-and-exploration.md |
| 入口可见却无法到达 | 地标间真实连接/支撑面 | 补合法路径或修改拓扑候选 | 起点到目标可逐节点走通 |
| 悬浮读成落地 | 主体下方负空间和投影 | 打开间隙、补高度参照与一致投影 | 主体与支撑关系无歧义 |
| 动作被家具挡住 | 全动作扫掠包络、道具长度 | 移非核心资产、调路径或机位 | 中间姿态也不穿插 |
| 裁成竖幅失去关系 | 主体/目标/出口是否同可读 | 以叙事锚点非对称重构，不仅中心裁切 | 关键关系仍成立 |
| 色彩漂亮但灰阶混 | 大明度结构和局部光域 | 分离主/辅明度，降低次要彩度 | 灰阶与彩色均可读 |
| 光斑抢戏 | 最高对比是否落在错误位置 | 缩光域、降地面高光、保持光源解释 | 第一眼回主任务 |
| 世界观像随机装饰 | 形体与资源/功能/痕迹关系 | 删无功能符号，以使用证据替代 | 每个独特点可说明原因 |

完成示例（设计演练）：仓库通道宽景中，亮窗抢走搬运目标。先保留窗位置和路径，只降低窗周边对比、在目标背后留安静暗面；再放中性搬运占位检查肩部与箱体扫掠。若仍被货架挡住，回布局层，不继续调色。
