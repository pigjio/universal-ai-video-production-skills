# Director Decision Layer — 书籍蒸馏的导演决策层

> 适用性：本参考提供条件性导演方法与演示案例，不是所有项目的固定镜序。无人物时人物心理/肢体条目不适用；非叙事用观看/感知任务。示例中的物件、数字、子镜编号只示范机制，不自动成为项目约束；选择省略、长镜头、反应或切镜应由当前任务与可读性验证决定。

> 本模块只收录可追溯到分镜 10 本书蒸馏稿的通用方法，不包含 Seedance / Dreamina、参考图槽位、DO / Clip、版本晋级或其他 AI 视频生产规则。

## 1. 导演的控制对象：观众体验

导演不是把剧本文字逐句转成画面的执行者。导演通过构图、视点、调度、剪辑、声音与时间，控制观众：

- 此刻先看哪里、随后看哪里；
- 知道什么、暂时不知道什么；
- 正在追问什么；
- 何时理解动作、关系与情绪变化；
- 在哪里停留、期待、误判或得到答案。

分镜师因此不是“画剧本”，而是把剧本重新组织为观众可以经历的视觉叙事。

**来源：**
- Francis Glebas, *Directing the Story*：导演观众注意力、叙事问题与情绪体验。
- Walter Murch, *In the Blink of an Eye*：观众眼迹、误导、情绪切点与适度省略。
- Steve D. Katz, *Film Directing Shot by Shot*：viewpoint、lens perspective、narrative motion 与预视觉化。
- Nancy Beiman, *Prepare to Board*：storyboard 作为 visual script，而非剧本文字插图。

## 2. 场级导演判断

逐镜前先回答：

1. **Goal：** 角色在本场想要什么？
2. **Opposition：** 谁或什么阻止他？
3. **Decision-Action：** 阻力迫使角色做出什么决定，并采取什么新行动？
4. **Audience Question：** 观众此刻追问什么？答案何时给出？
5. **Information Distribution：** 角色与观众分别知道什么？什么必须暂缓揭示？
6. **Emotional Change：** 观众应从什么情绪走向什么情绪？哪个变化需要停留读取？
7. **Visual Strategy：** 这一变化主要由视点、调度、构图、光色、运动、剪辑还是声音完成？

“电影性来自什么”不能用“更电影感”回答，必须落到具体可见、可听、可剪的手段。

**来源：**
- Goal / Opposition / Decision-Action：Glebas。
- 观众问题与信息分配：Glebas、Murch。
- 视点、调度与视觉化：Katz、Alexander Mackendrick、Joseph V. Mascelli。
- 视觉结构：Bruce Block、Marcos Mateu-Mestre。

## 4. Story Beat 增强字段

每个 beat 至少记录：

```text
Beat 编号：
角色目标：
阻力：
可见行动：
观众问题：
信息变化：
情绪变化：
Reaction：
Decision-Action：
下一 beat 钩子：
```

### Reaction

Reaction 不是机械补镜。它把前一动作从“发生了什么”转成“这意味着什么”。设计反应时必须写清：

```text
触发物 / 前一动作
→ 可见的身体、眼神或呼吸变化
→ 思考停顿
→ 新情绪或新理解
→ 后续决定 / 行动
```

反应镜头是否成立，取决于它前后连接了什么，而不只取决于表情本身。

### Decision-Action

决定必须通过后续可见行动得到证明。不要把“看见”“被吸引”“受到鼓励”直接当成角色已作出选择；角色改变要由新的姿态、方向、接触、拒绝、迈步或其他行动兑现。

**来源：**
- Reaction 与镜头顺序：Glebas、Murch。
- Goal / Opposition / Decision-Action：Glebas。
- thinking time、眼睛先于头和身体、情绪转折：Richard Williams。

## 5. 观众注意力接力

每个镜头设计两条路径：

```text
镜内路径：第一眼焦点 → 触发 → 第二眼焦点 → 停稳
镜间路径：上一镜眼迹 / 动作 / 声音 → 切点 → 下一镜兑现
```

可用手段包括：

- 角色视线；
- 运动方向；
- 明暗对比；
- 尺度与负空间；
- 声音先行；
- 前景遮挡；
- 焦点变化；
- 动作顺接。

不要完全控制观众的每一眼。若新增镜头没有增加新情绪、新信息或新节奏，应删除或合并。

**来源：** Murch 的 eye-trace / visual misdirection；Glebas 的兴趣中心与注意力保护；Mascelli、Katz 的视线匹配和连续性。

## 6. 导演技法功能闸门

使用推镜、拉镜、荷兰角、POV、过肩、反射、框中框、遮挡、跳切、叠化等技法前，回答：

1. 它解决哪个叙事问题？
2. 它改变了观众获得的信息、人物关系、空间理解、情绪强度或剪辑节奏中的哪一项？
3. 固定机位是否已经足够？
4. 它是否让主动作、主情绪或关键反应更难读？

若没有明确变化，默认不添加该技法。技术复杂度和技法数量不是质量指标。

**来源：** Katz 的 viewpoint / narrative motion；Mackendrick 的行动与调度优先；Murch 的 Rule of Six；Williams 的“先清楚，再复杂；先表演，再装饰”。

## 7. 克制、隐藏与清晰度边界

- 强情绪不必依赖夸张表情；先让观众理解角色的目标、失去和不可挽回性。
- 适度省略可以让观众参与补完；过度解释会削弱参与。
- Hold 不是死停；主动作停止后，可保留眼睛、呼吸、手指、衣物等微小活点。
- 省略不能破坏必要因果。关键动作的触发、结果或反应至少要让观众获得足够证据。
- 先清楚思想、行动、重量和情绪，再增加漂亮机位和次要动作。

**来源：** Glebas、Murch、Williams、*Timing for Animation*、*Framed Ink*。

## 8. 书籍来源边界

本模块允许进入通用 `storyboarding` skill 的内容，仅限：

- 观众注意力与叙事问题；
- Goal / Opposition / Decision-Action；
- Reaction、thinking time 与 Hold；
- 视点、blocking、构图、视觉结构；
- 眼迹、剪辑、声音与 Timing；
- 技法服务叙事、清晰度优先。

以下不属于本模块：AI 平台时长、DO / Clip 分组、上传素材、资源 ID、参考图槽位、真实生成尾帧、平台轮询、提示词负面项、生成模型稳定性、文件版本晋级。它们应由独立 AI 视频生产 skill 管理。
