> 适用性：本参考提供条件性导演方法与演示案例，不是所有项目的固定镜序。无人物时人物心理/肢体条目不适用；非叙事用观看/感知任务。示例中的物件、数字、子镜编号只示范机制，不自动成为项目约束；选择省略、长镜头、反应或切镜应由当前任务与可读性验证决定。

用于已有 Beat List / Shot List 之后，把简表升级为可直接进入 Thumbnail、Animatic、Layout、Animation 与图片分镜的逐镜头导演描述。

## 1. 目标

详细描述不等于把同一句剧情换词重复。每个镜头应成为独立的视觉叙事单位：

- 一个主要叙事任务；
- 一个主要视觉焦点；
- 一个明确的信息或情绪变化；
- 一个能够接入上一镜与下一镜的动作状态；
- 一个可供动画、剪辑或图片分镜执行的稳定落点。

全片共用的风格、角色外观、材质和世界规则在文档前部统一声明一次。逐镜头只记录该镜头新增、改变或需要特别控制的内容。

## 2. 何时拆镜

当一个镜头同时承担多个关键阶段，且合在一起会削弱理解或张力时，按动作因果拆开：

```text
Anticipation → Action → Contact / Failure → Reaction → Aftermath / Decision
```

优先拆分：

1. 关键动作的准备与真正发生；
2. 重要信息揭示与角色反应；
3. “差一点成功”的距离变化；
4. 道具状态改变；
5. 失败结果与角色重新选择；
6. 必须让观众看清的因果证据；
7. 需要独立 Hold 的情绪节点。

示例：

```text
角色伸手救伙伴
→ 两只手靠近
→ 指尖只差一点
→ 阻力介入
→ 手被推回
→ 伙伴看见角色确实伸过手
```

## 3. 何时不拆

以下情况不应新增镜头：

- 拆开后没有新增信息、情绪、动作或节奏功能；
- 只是同一动作的多个装饰性角度；
- 反应已经能在同一构图中清楚读到；
- 拆镜破坏动作连续性或空间理解；
- 为了“电影感”机械堆叠特写；
- 把每个细小动作都切碎，导致节奏失去呼吸。

判断句：**拆开后是否更清楚、更紧张或更有情感重量？如果没有，就不拆。**

## 4. 单镜头描述字段

```text
镜头编号 / 对应 Beat：
预计时长：
叙事任务：
观众问题：
景别 / 角度 / 焦段倾向：
摄影机位置与运动：
开始构图：
前景 / 中景 / 背景：
角色与道具位置：
第一眼焦点：
第二眼路径：
动作过程：Anticipation / Action / Reaction / Aftermath
表演：视线、表情、呼吸、身体重心、手部接触
明暗 / 色彩 / 负空间功能：
声音节拍：
信息隐藏 / 揭示：
精确剪辑点：
与上一镜的连续关系：
稳定尾帧 / 下一镜钩子：
避免事项：
```

字段不是越多越好。静物插入镜头不必硬写完整角色表演；动作镜头必须详细写动作过程、重心和接触；空间建立镜头必须详细写地标、方向和人物路线。

## 5. 非重复写作规则

### 文档级信息只写一次

- 项目视觉风格；
- 固定角色外观与服装；
- 场景基础布局；
- 世界规则；
- 全片统一色彩和材质禁令。

### 镜头级只写变化量

- 本镜头新增的焦点；
- 人物相对上一镜的位置、方向、情绪和动作变化；
- 道具的新状态；
- 光线或色彩因剧情发生的变化；
- 当前镜头独有的机位、运动、切点和尾帧。

不要在每个镜头重复“高质量 3D 动画电影画质、柔和全局光照、细腻材质”等固定描述。

## 6. 连贯性控制

拆镜后逐镜检查：

- 动作入点是否继承上一镜出点；
- 手中道具、接触手、身体重心是否连续；
- 角色屏幕方向和视线是否连续；
- 第一眼焦点是否从上一镜眼迹自然接入；
- 地标、入口、出口和路线是否仍清楚；
- 若越轴，是否先用宽镜、角色转身或摄影机过轴重新定向；
- 稳定尾帧是否能成为下一镜或 Image-to-Video 的可继承起点。

### 6.1 动作执行审计：不能只检查“发生了什么”

逐镜描述进入 Layout / Animation / AI 视频前，还要做一次**物理执行链审计**。很多文字在剧情层成立，但落到动画时会暴露换手、瞬移、重力错误或动作过载。

对每个连续动作明确：

```text
执行手：左手 / 右手 / 双手
起始状态：手里原本拿着什么、位于哪个表面
接触点：手从哪里接触人物或道具
运动路径：经过哪些空间或表面
结束状态：道具最终在哪里、手是否仍持有
下一镜继承：下一镜从哪个姿态和道具状态开始
```

重点检查：

- 不写含混的“另一只手”“手抓起”，应在关键动作首次发生时明确左右手；
- 同一只手不能在未交代放下道具的情况下立即操作另一件物品；
- 道具从斜面到水平面的滑动、滚动或混合运动取决于形状、摩擦、受力和初始状态；记录实际路径、接触面与运动转换，不把某种顺序当作通用物理规律；
- 受重力影响的物件停留须符合形状、摩擦、黏附或支撑条件；若现有条件不足，补已成立的挡条/夹具等依据，不要求所有斜面物件必有挡条；
- 镜头尾帧只保留本镜真实完成的状态，不要把下一镜才发生的“放回、拿起、转身”提前写进尾帧；
- 一个镜头若同时出现取物、使用、放回、换目标、推移和松手，应检查是否动作过载；必要时拆镜，或明确主动作与过渡动作的层级。

### 6.2 空间锚点与关键道具拓扑审计

仅写“道具在斜面 / 平面”还不够。连续图片分镜、Layout 或 AI 视频生成会把每镜当作可重新解释的场景；若没有固定坐标，人物、Hero Prop 和辅助道具会在镜头间跳位。因此，在逐镜扩写前先建立一份 **Spatial Anchor Registry（空间锚点表）**：

```text
空间母版：房间 / 工作区 / 画板 / 桌面 / 镜子
固定锚点：人物座位、Hero Prop 固定点、左右前后道具区、入口与镜座
人物基准：身体中线朝向、座位、屏幕方向、左右手职责
道具拓扑：A 在 B 的左前 / 右后 / 上方 / 下缘，不用“附近、桌角、边缘”
固定机制：夹具、挡条、支架、槽口、重力方向
合法状态变化：不动 / 被遮挡 / 解夹取下 / 移至新锚点
非法变化：未交代即平放、换边、旋转、缩放、被推走或回到原位
```

#### 逐镜位置字段

关键镜头除动作外，至少明确：

```text
人物：位于哪个固定座位或路线节点，身体中线朝向哪里
Hero Prop：固定在哪个结构上，当前是否移动
辅助道具：相对人物的左前 / 右前 / 更远右侧等锚点
执行手：左手 / 右手
运动路径：从哪个锚点出发，经过哪里，到哪个锚点结束
继承状态：下一镜必须保留什么
```

#### Hero Prop 不动时的叙事替代

若核心道具已经固定在画板、墙面、平台或设备上，不要为了表达“回避”随意推动它。优先改变：

- 遮挡关系：用另一张纸、身体或前景遮住关键区域；
- 注意力：人物转头、闭眼、伏下或移开视线；
- 可见范围：换景别或利用景深，不改变实际位置；
- 合法状态：先明确解夹、解锁、取下，再移动到新锚点。

#### 特写连续性原则

特写可以省略大部分环境，但必须保留至少一个位置证据，例如固定夹、挡纸条、桌面下缘、地标边缘、同一缺口方向或稳定的入画方向。**摄影机改变画面占比，不等于场景资产重新排布。**

#### 跨场回收

开场建立的空间必须在回归场景中按状态机恢复，而不是用“拉回原位”掩盖前文没有合法移动的问题。先核对上一场真实尾帧，再设计：

```text
遮挡仍在 → 人物移除遮挡 → Hero Prop 原位显露
完成固定资产 → 明确解夹 / 解锁 → 取下 → 放到新锚点
```

完成后同时回归搜索详细分镜、Shot List、资产清单、联系表 Prompt 和视频 Prompt 中的旧空间词与旧动作，例如“推高、拉回、移到侧方、桌角、两块表面”，直到残留为零或标明历史版本。

### 6.3 信息递进审计：相邻镜头不能提前演完下一镜

相邻镜头应形成“引导 → 揭示 → 升级”，而不是两镜重复完整信息。

典型分工：

```text
角色反应 / 视线改变
→ 下一镜完整揭示对象
→ 再下一镜进入接触或动作
```

异常事件也应分级：

```text
普通暗反射
→ 微弱光点 / 声音种子
→ 明确形态变化
→ 危机或角色出现
```

审核问题：

- 当前镜头是否已经把下一镜的主要视觉事件演完？
- “先看反应，再看对象”和“先看对象，再看反应”是否被无意混用？
- 这一镜只制造问题，还是也过早给出了答案？
- 相邻两镜若都展示同一对象，二者是否分别承担情绪转折与信息揭示？

### 6.4 多版本文档同步闸门

逐镜版本优化后，对实际存在且授权管理的以下产物做影响检查；仅修订受影响依赖，未授权部分交付待办，不静默覆盖批准稿：

1. 生产控制包 / Shot List 简表；
2. 联系表与图片分镜 Prompt；
3. 场景母版或资产布局说明；
4. AI 视频 Clip / 派生图提示词；
5. Animatic 时长表与镜头编号统计。

简表允许合并摘要，但须保留到详细版子镜稳定 ID、版本及时间范围的映射，不复用同一 ID 表示不同镜头。修订后按 `references/timing-verification.md`（相对技能根目录）复核编号、时长和映射，并检查旧空间词、旧道具位置和旧事件层级；历史内容保留版本标记，不要求不同用途文档全文相同。

## 7. 节奏与总时长闭环

镜头时长不能平均分配：

- 环境证据与规则展示：短、清楚、递进；
- 关键准备动作：给 anticipation；
- 犹豫、认知变化和情感回收：给 hold；
- 冲击或失败：用 accent；
- 动作爆发：缩短镜头或加快 spacing；
- 结果意义：保留 reaction / aftermath；
- 高潮应形成明确的快慢曲线，而不是持续加速。

### 先分配预算，再逐镜扩写

不要先把所有镜头写完，最后才发现总时长严重超标。开始逐镜写作前先锁定：

```text
全片目标时长
→ Scene 时长预算
→ Beat 时长预算
→ 关键 Hold 保护清单
→ 其余镜头可压缩池
```

每完成一个 Scene 计算其镜头时长合计并记录预算差额；完整演绎稿可标暂不锁时。时间精度按项目帧率、剪辑需求与工具约定，不设固定秒数网格。

### 时长偏差的修正顺序

如果逐镜拆分后超出预算，按以下顺序压缩，而不是直接删除关键剧情：

1. 缩短环境证据和已被理解的规则展示；
2. 用 J-cut / L-cut、动作重叠或声音桥合并相邻准备动作；
3. 合并功能相同的群众或生态反应；
4. 缩短非关键尾帧 hold；
5. 最后才考虑删镜。

禁止优先压缩：主题选择、失败后的 Reaction、关系回收、关键接触前的“差一点”、角色主动改变旧模式的 Hold。

### 详细动作板与 Animatic 的口径

“为了讲清动作而拆出更多镜头”不等于可以忽略片长。若确实需要保留详细动作板与目标 Animatic 两种口径，必须明确标注两者，并给出逐 Scene 的压缩映射；不得在文档末尾只写“以后压缩”。生产版逐镜文档默认应直接闭环到目标片长。

加载 `references/timing-verification.md`（相对技能根目录），按其中输入表、工具算术和回归步骤核查编号唯一性、项目要求的顺序、预期镜数、分段时长和全片总时长；没有实际运行不得声称自动验收通过。

### 7.1 节奏吸引力审核：不要把“镜头多”误判为“节奏快”

文字分镜进入 Animatic 前，先做一次定量与叙事双重审核：

1. 统计总镜数、平均镜长、每场镜头密度，以及 1s / 1.5s / 2s 等高频时值占比；
2. 找出连续多个相同时值的镜头链，检查 Anticipation、Action、Reaction、Hold 是否被机械赋予同等时间；
3. 为每个时间段写一个主要观众问题，检查镜头是否持续制造、升级、延迟或回答该问题；
4. 用删镜测试找出“重复证明同一规则”“逐项展示恢复对象”“连续多个结尾确认”等低收益镜头；
5. 明确保护 Hold：主题选择、失败后的 Reaction、关系回收、“差一点”接触、改变旧模式的动作不得优先压缩。

关键判断：**快节奏来自信息与情绪变化，不来自大量短镜头；慢节奏来自有效期待和读取，不来自平均拉长。**

### 7.2 同功能合并后如何保持目标片长

当清单式镜头被合并后，不要为了恢复旧镜数重新制造重复镜头。若目标片长不变，把省下的时间重新分配给：

- 复杂因果传播的读取；
- 角色真正理解事件意义的 Reaction；
- 关键选择前的悬停；
- 情感接触完成后的短暂 Hold；
- 高潮后的整体释放和结尾余韵。

推荐流程：

```text
合并同功能镜头
→ 计算节省的秒数
→ 按“可读性 / 情感重量 / 主题重要性”排序保护节点
→ 将时间加到镜内动作与Hold，而不是新增装饰镜头
→ 重新校验Scene与全片总时长
```

### 7.3 主动性闸门：外力提供信息，不应被误称为角色选择

仅当本场主题是“无人推动仍主动改变”时，以下顺序是可选证明方式；被鼓励后自主决定也是合法行动，不强制孤立无援：

```text
无人注视 / 无奖励
→ 旧习惯或恐惧真实回返
→ 角色独立决定并行动
→ 角色拒绝旧模式
→ 伙伴、魔法或环境回响最后出现
```

外部信息或鼓励出现后，仍检查角色实际可选的替代方案和证明决定的动作。若作品要证明“即使无人鼓励也行动”，则把支持放到行动之后；其他主题无需服从这个排序。

### 7.4 事件状态与局部成功不可回滚

高潮中的规则展示必须维护事件状态机。对每个对象记录：

```text
未完成 → 被补线 → 动作完成 → 持续运行
```

后续危机可以压制光色、汇聚到结构根源或制造新阻力，但除非剧情明确要求失败，不能让已完成对象无说明地重新冻结。否则观众会认为之前的动作无效，形成假高潮。

对触发事件记录形成、等待、接触和结果的有序状态。两个状态可以在同镜、同场异镜或跨场发生，由叙事边界和可读性决定，不强制拆 Scene；仅当已批准的场间信息边界要求延后结果时保护该边界。受影响产物保持状态含义与版本映射一致，不要求文字相同。

### 7.5 节奏修订后的回归搜索

重编号或合并镜头后，除按 `references/timing-verification.md` 复核外，还应在授权管理的受影响产物中搜索：

- 已删除的旧镜号和旧交叉引用；
- 旧事件状态词；
- 已废弃的节奏描述；
- 仍提前出现的外部提示；
- 文末旧镜数、旧时长和“每镜对应一个Clip”等说明；
- 审核报告中应保留为“历史问题”的文字，需明确标注已修正，避免与当前 Canon 混淆。

最终交付条件不是“文字已经改完”，而是：**稳定 ID 唯一且顺序/映射明确、镜数正确、分场时长正确、总时长闭合、旧表述无未标记残留。** 连续编号仅在项目明确要求时检查。

### 7.6 生成时长与镜头粒度分离

AI 视频生产中必须区分：

- **生成单元时长**：一次请求覆盖的连续剧情长度；
- **内部剪辑镜头粒度**：该请求内逐镜指令的时间与因果拆分精度。

生成单元长度由当前平台能力、实测稳定性、连续性需求与成本决定，交由生产阶段核验，不设通用推荐秒数。内部镜头粒度按主要观看任务、动作负载与信息读取决定；不能从生成请求长度反推每镜时长。

典型拆法：

```text
环境压迫 → 异常流向 → 聚形完成
蓄力 → 起扑 → 角色切入
落第一笔 → 轮廓闭合 → 实体化
接近 → 接触 → 散开／改道
受力 → 反作用传导 → 道具受损特写
```

一个镜头可以连续呈现多个动作阶段；只有注意力竞争或读取时间不足时，才延长、简化、移切点或拆镜，并用动作匹配、视线匹配或声音桥维持连续。生产测试按能力和成本选择范围；局部失败优先定位后补测，不要求先生成完整长段，也不因内部镜头多就机械拆请求。

## 8. 逐镜头质量闸门

每镜完成后回答：

1. 观众第一眼看哪里？
2. 本镜头唯一主要任务是什么？
3. 相比上一镜，新增或改变了什么？
4. 角色动作是否包含足够的准备、接触、结果或反应？
5. 为什么现在切，而不是更早或更晚？
6. 下一镜如何继承动作、眼迹、方向和情绪？
7. 如果删掉此镜，故事、情绪或节奏是否受损？

第 2、3 或 7 题答不上来，镜头通常应删除、合并或重写。
