# 完整演绎版与后期压缩

> 适用性：本参考提供条件性导演方法与演示案例，不是所有项目的固定镜序。无人物时人物心理/肢体条目不适用；非叙事用观看/感知任务。示例中的物件、数字、子镜编号只示范机制，不自动成为项目约束；选择省略、长镜头、反应或切镜应由当前任务与可读性验证决定。

## 适用情境

用户明确要求先不限制时长、先把剧情和表演完整演绎，再在动态分镜或 animatic 阶段删减。适用于心理表演、第一次异常触发、道具因果链、高潮前停顿和无对白叙事。

## 核心原则

文字分镜首先要回答“完整动作如何发生、观众如何读懂”，而不是先满足最终秒数。一个旧版时长如果压缩了多个独立注意力变化，不能直接沿用；应暂时建立完整演绎稿，并明确它是可剪辑母稿，不是最终锁时版本。

## 拆节拍规则

把一个复杂动作拆成可独立删减的连续节拍：

1. 准备：角色或道具进入状态，观众理解目标。
2. 迟疑或 anticipation：动作为什么没有立即完成，心理或物理阻力在哪里。
3. 执行/接触：动作真正发生，方向、手、支撑面和接触点清楚。
4. 结果：道具、环境或角色状态发生可验证变化。
5. 反应：角色读到结果，表情、姿态或视线改变。
6. 等待/触发：结果已经稳定后，异常、声音或下一事件才响应。

这是含人物反应与触发的复杂动作检查表，仅写当前任务存在的阶段；没有迟疑、接触或人物反应时标不适用。不要求各阶段独立成镜。后期压缩时可以：

- 删除纯重复证明；
- 把 preparation 与执行合并；
- 缩短已经读懂的 hold；
- 用动作匹配剪辑跨过中间过程；
- 保留接触、结果和关键反应；
- 保留异常触发前的静半拍，除非 animatic 证明它不产生信息或情绪价值。

## 时长处理

不要为了让页头时长好看而修改镜头标题、重复时间码或压扁动作。完整演绎版可以暂时超出原片长，页头应明确标注工作状态，例如“完整演绎版 / 暂不锁时”。若需要计算一个暂时总时长，必须由每镜时长相加得到，并在文件中标注“待 animatic 压缩”，不能把它误称为最终片长。

推荐建立两种时间口径：

- **母稿时长**：完整表演的自然时长，允许 Hold、呼吸、反应和物理等待。
- **剪辑目标时长**：进入动态分镜后，根据可读性和节奏压缩得到的版本。

除非用户明确要求，不能从高潮或其他场景随意抽走时间补给第一幕。若需要维持全片总长，应先记录为待重新预算，而不是暗中削短其他场景。

## 典型案例：小道具触发异常

“角色放下铅笔 → 角色伏下 → 铅笔滚动 → 铅笔碰到镜座 → 铅笔停稳 → 静半拍 → 镜面起波纹”不应在一个 2-3 秒镜头中全部完成。完整演绎稿至少要让观众读到：

- 铅笔确实放在桌面上；
- 角色动作不是直接导致异常，而是衣袖或惯性使铅笔开始滚动；
- 铅笔没有离开支撑面，滚动方向和镜座位置明确；
- 接触结果先完成，镜面随后才回应；
- 若角色尚未察觉，不应提前表演对异常的反应；可留在任意合理景别，只要表演符合其知情。

这个结构尤其适合无对白 AI 视频，因为声音顺序可以补足视觉因果：放下声 → 衣料擦碰 → 滚动声 → 接触声 → 声音落定 → 异常水声/共鸣。

## Animatic 复审顺序

完成完整演绎稿后，不要凭文字直觉删减。按以下顺序播放动态分镜：

1. 先检查观众是否知道每个动作的目标和结果。
2. 再检查心理节拍是否过长，哪些 Hold 没有新增信息。
3. 标记可以动作匹配的镜头对。
4. 标记可以跨声音桥合并的镜头对。
5. 只删除重复读取，不删除第一次建立规则、失败、选择和异常触发的证据。
6. 导出压缩版后，再逐对检查尾帧到起帧的动作、道具和声音连续性。

## 常见错误

- 把“暂不限制时间”误解为无限增加装饰镜头。完整演绎仍要围绕剧情功能，只是暂不压缩有效表演。
- 直接把旧版时长套到新版镜头上，导致每镜承担多个心理和动作阶段。
- 为维持总片长未经确认削减战斗或其他场景。
- 只增加镜头数量，却没有增加独立注意力变化。
- 让异常紧跟物理接触出现，缺少结果确认和静半拍。
- 完整稿和剪辑稿混在同一个“最终版”文件里，导致动态分镜阶段不知道哪些时长可以删。
