# Storyboard Methodology Map — 分镜方法与书目索引

本文件由源版 storyboarding 的同名方法地图改编。下表是既有书目与方法归属索引，不代表本次重新核验原书全部内容或页码；源蒸馏档案未随包提供，不作为执行前置条件。执行以本包正文与条件参考为准，迁移范围见 `source-map.md`。

## 1. 十本书的分工

| 书籍 | 核心贡献 | 系统位置 |
|---|---|---|
| Directing the Story — Francis Glebas | 观众体验导演、故事问题、Goal/Opposition/Decision-Action、beat、story reel、pitch | 把剧本重新写成观众注意力与情绪变化的镜头序列 |
| Prepare to Board — Nancy Beiman | 动画分镜作为视觉剧本、log line/story line、outline/treatment、thumbnail、角色与故事规则 | 从故事种子进入动画分镜生产，建立缩略图与便利贴迭代法 |
| Film Directing Shot by Shot — Steve D. Katz | 视觉化管线、storyboard、floor plan、镜头符号、景别、轴线、运动镜头、previs | 把戏剧问题转成可拍镜头、调度图与预演方案 |
| The Five Cs of Cinematography — Joseph V. Mascelli | Camera Angle、Continuity、Cutting、Close-up、Composition | 建立摄影机角度、连续性、剪辑和构图的工业语法 |
| The Visual Story — Bruce Block | 空间、线、形、明度、色彩、运动、节奏、对比与和谐 | 把分镜组织成可控的视觉结构和强度曲线 |
| Framed Ink — Marcos Mateu-Mestre | 构图、明暗块面、光线、负空间、尺度、视觉叙事 | 用单格画面控制观众理解、情绪与叙事重点 |
| On Film-Making — Alexander Mackendrick | 电影语法、blocking、行动、关系变化、道具 business、视觉化练习、POV、轴线 | 让场面调度服务戏剧行动，而非漂亮摄影 |
| In the Blink of an Eye — Walter Murch | 剪辑思维、Rule of Six、情绪优先、眼迹、节奏、误导 | 在分镜阶段提前设计剪辑可成立的观看路径 |
| Timing for Animation — Whitaker & Halas | Timing、Spacing、Hold、Anticipation、重量、惯性、节奏、口型 | 把静态分镜推进成能读懂动作质地的 animatic 时间设计 |
| The Animator's Survival Kit — Richard Williams | 12 动画原则、Key/Extreme/Breakdown、重量、走跑、重叠、慢入慢出 | 让分镜动作具备动画可执行的姿势、节奏和运动逻辑 |

## 3. 管线定位

```text
头脑风暴 → 剧本 → 角色设计 → 环境概念设计 → 分镜 → Animatic / Previs / Layout / Animation
```

分镜是视觉导演层，职责不是补全所有上游缺失信息，而是把上游约束转成镜头、节奏、空间、动作与剪辑。

## 4. 概念索引

### Story Beat

一个有明确观看职责的推进单位。叙事转折按适用性检查目标、阻力、动作、信息/情绪变化和后果；感知/概念段落检查观看变化、操作条件和结束判据，不强补人物冲突。

### Thumbnail

粗略小图，用来快速测试镜头方案。核心标准是清晰、可重排、可比较，而不是漂亮。

### Blocking / Floor Plan

俯视调度图。用于明确角色位置、路线、摄影机位置、轴线、视线方向、道具与出入口。

### Shot Card

分镜的最小生产交付单位。记录景别、角度、运动、动作、表演、信息、时长与剪辑点。

### Rule of Six

剪辑优先级：情绪 > 故事 > 节奏 > 眼迹 > 二维平面 > 三维空间。分镜阶段用于判断切点和镜头顺序。

### Timing / Spacing

Timing 决定动作意义，Spacing 决定动作感觉。分镜如果不标 timing，动画阶段会失去表演逻辑。

## 5. 关键原则

- 分镜不是画剧本，而是重新导演观众体验。
- 每个镜头本质上都是一个 close-up：它必须让观众注意某个具体叙事重点。
- 观众问题比事件列表更重要。
- 清晰度优先于画面完成度。
- 反应镜头常常比动作镜头更能传达意义。
- 轴线不是死规则，而是观众空间理解的稳定器。
- 情绪切点优先于技术连续性。
- 静态分镜必须经过 animatic 的时间验证。
