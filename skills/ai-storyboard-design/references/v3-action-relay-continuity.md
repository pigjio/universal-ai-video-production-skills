# V3 式动作接力与镜间连续性

> 适用性：本参考提供条件性导演方法与演示案例，不是所有项目的固定镜序。无人物时人物心理/肢体条目不适用；非叙事用观看/感知任务。示例中的物件、数字、子镜编号只示范机制，不自动成为项目约束；选择省略、长镜头、反应或切镜应由当前任务与可读性验证决定。

## 适用问题

当逐镜分镜的单镜构图、主体位置和道具状态都很清楚，但观看时仍像一组独立镜头，缺少动作与动作之间的连续推进时使用。

常见成因不是“镜头数量少”，而是生成平台的 Clip / DO / Narrative Job 反向压缩了导演动作层：一个短镜头内同时完成准备、接触、结果、反应与下一动作，导致动作虽按顺序写出，却没有重量、眼迹和接力。

## 正确层级

```text
Canon / Story Beat
→ 完整动作链
→ 导演镜头与剪辑点
→ Animatic
→ Clip / DO 生成分组
→ 10/15 秒平台窗口
```

Clip / DO 可以合并多个导演镜头，但不能反过来决定动作链应删掉哪些必要阶段。

## 动作链模型

先把事件写完整，再决定切点：

```text
Anticipation
→ Action Start
→ Contact / Failure
→ Result
→ Reaction
→ Aftermath / Decision
```

不是每一步都必须独立成镜；只有当拆开能增加清晰度、张力、情绪重量或生成稳定性时才拆。但关键接触、失败结果和人物反应不能因为镜数预算而全部压在同一短镜头中。

## 两类尾帧

### 1. 动作接力尾帧

上一镜停在动作势能仍存在的位置，下一镜继续完成：

- 笔尖距纸几毫米；
- 身体失去支撑开始下坠；
- 手腕刚被抓住；
- 道具刚开始滚动；
- 人物刚完成转身并迈出第一步。

### 2. 反应接力尾帧

动作完成后留下明确的下一动机：

- 视线转向橡皮；
- 角色看见失败结果；
- 萌物看见男孩伸出的手；
- 肩膀下沉、手指松开；
- 目光停到下一镜将揭示的对象。

“人物和道具已停稳”只适合段落收束或生成续接，不应成为所有镜头的默认尾帧。

## 镜头对审查表

逐对检查，而不是只检查单镜：

| 项目 | 要回答的问题 |
|---|---|
| 上镜最后动作 | 谁的哪个身体部位或道具正在做什么？ |
| 上镜尾帧状态 | 姿态、重心、左右手、道具、方向是什么？ |
| 下镜第一动作 | 是继续、完成、受力、反应，还是全新动作？ |
| 接力类型 | 动作匹配、视线匹配、声音桥、结果切、反应切？ |
| 动作是否重启 | 下一镜是否重复了已经完成的准备动作？ |
| 缺失阶段 | 接触、结果、反应、余波中缺了哪一层？ |
| 修复方式 | 改尾帧、改起帧、移动切点、重分时长或局部拆镜？ |

修正后再看三镜链：

```text
A 镜启动
→ B 镜完成 / 受力
→ C 镜兑现结果 / 反应 / 新决定
```

## 高风险指向动作：锁定目标与伸肢结果分镜

当 AI 视频模型需要同时理解“小型角色看准远处局部、抬爪／抬手、沿斜线伸出、爪尖对应目标、随后收回并转向第二目标”时，即使动作总长只有 1–2 秒，也不要把整条链压在一个镜头里。多主体、远近两层和细小肢体方向同时变化，容易造成指错对象、换爪、穿模、提前转头或把两个目标混在一起。

优先拆为同一原镜号下的 `A/B` 子镜，避免无必要地重编号下游：

```text
A｜目标锁定与抬肢蓄势
- 眼睛和头部先锁定唯一目标；
- 指向肢体只抬到胸前／预备点；
- 明确尾帧尚未到达目标，也不启动下一目标动作。

B｜沿唯一轨迹完成指向
- 严格继承 A 的头部、眼线、肢体起点；
- 沿唯一屏幕矢量伸直；
- 明确爪尖／指尖终点、是否接触、停留时间；
- 其余肢体保持稳定；
- 尾帧把真实伸直姿态交给下一镜沿原路径收回。
```

执行规则：

1. **拆镜不等于加时。** 默认把原镜总时长在 A/B 间重分，场级与 DO 总时长不变；只有动作可读性确实不足且用户允许时才扩时。
2. **局部增密，其他镜头不膨胀。** 只对高风险动作增加起点、路径、终点、停留、视线和尾帧细节；不要借机重写整组。
3. **声音跨切接力。** 提示短音可在 A 的抬肢时启动、在 B 的伸直时收束，环境声跨切连续。
4. **第二目标必须后置。** 若下一镜还要收肢、转头并指向另一对象，B 只完成第一个目标；下一镜从 B 的真实伸直尾帧沿原路径收回，再启动转头。
5. **容量受限时优先保留这段细节。** 可从组头重复说明和低风险摄影解释中回收字符，不能再次压缩高风险指向链。

拆分后验收：A/B 时长之和等于原镜；镜号顺序唯一；A 尾帧与 B 起帧一致；使用同一只手／爪；目标、轨迹、终点与接触关系唯一；下一镜不重启抬肢动作。

## 眼迹与声音胶水

- 上一镜的动作方向、视线或明暗变化，应提前把眼睛送到下一镜主体。
- 声音可跨切延续：滚动声、呼吸、摩擦、液面拉伸、脚步等，使镜头切换仍属于同一事件。
- 接触声必须落在真正完成接触的镜头；反应镜头可保留接触声余响或环境突然收窄。

## 正向描述与连续性兼容

逐镜正文使用正向可见内容时，不要因此把每镜重写成独立完整画面。应保留正向的关系性句式：

- “延续上一镜同一轴线与同一右手入画方向……”
- “承接下坠，身体从画面上缘落入……”
- “右手保持上一镜悬停姿态，左眼先转向……”
- “滚动声延续，铅笔从画面左侧进入……”

这不是负面提示，也不是重复空间说明，而是动作接力证据。

## 压缩策略

当总时长和镜数已锁定时，优先：

1. 合并重复环境证明和装饰性反应；
2. 缩短无功能 hold；
3. 在现有镜头间重新分配秒数；
4. 移动切点，让动作跨镜；
5. 最后才考虑删除接触、结果或关键反应。

平台固定窗口的余量用于自然 hold 或后期裁切，不新增动作，也不以压缩导演动作链来适配窗口。

## 最终验收

- 每个重要动作至少读到准备、接触、结果中的三个节点；情绪关键动作还需反应。
- 下一镜不重新执行上一镜已完成的动作。
- 每个切点都有动作势能、注意力变化、声音节点或情绪理由。
- 单镜主体位置明确，同时镜间身体重心、左右手、道具与运动方向连续。
- Clip / DO 分组改变生成方式，不改变导演动作逻辑。
