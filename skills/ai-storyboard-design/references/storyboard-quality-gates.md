# Storyboard Quality Gates — 分镜质量闸门与修复策略

用于正式交付/生产验证，按范围选择单格、序列、连续性、时间和交接检查；讨论不以母版、动作测试或完整生产包过闸。无人物条目不适用，静态构图不强制 Animatic，感知与概念任务不强造冲突。有意隐藏的信息按揭示时间检查，不把全部清晰视为通用目标。

## 1. 单格质量闸门

每一格至少通过以下检查：

- [ ] 第一眼焦点明确
- [ ] 第二眼路径可控
- [ ] 角色剪影清楚
- [ ] 景别服务叙事功能
- [ ] 角度服务权力 / 心理 / 信息关系
- [ ] 背景不抢戏
- [ ] 动作可见可读
- [ ] 明暗块面能引导视线
- [ ] 负空间有叙事用途，而非空洞
- [ ] 道具或细节不会误导观众

### 常见问题：画得漂亮但看不懂

症状：细节丰富，但观众不知道看哪里。

修复：

```text
1. 降低背景细节；
2. 做黑白灰大块测试；
3. 加强角色剪影；
4. 删除与当前 beat 无关的视觉信息；
5. 用光线或负空间推焦点。
```

## 2. Story Beat 质量闸门

叙事压力型 beat 按适用性核对以下项；无人物段落改用材料/空间约束、观看变化、观察指标和结束判据：

```text
角色目标
阻力
动作
观众问题
信息变化
情绪变化
下一 beat 钩子
```

先检查信息、情绪、感知节律、空间认识或有意停留的功能；全部无作用才删或合并，不为保留段落强造冲突。

### 常见问题：逐句翻译剧本

症状：每句台词都被画成一格，镜头多但没有转折。

修复：按转折拆 beat，不按台词拆镜头。问：这句话改变了什么？如果没有改变，就不应单独占一格。

## 3. 序列质量闸门

整个镜头序列必须通过：

- [ ] 每个镜头都有功能
- [ ] 镜头顺序保留因果
- [ ] 重要反应镜头没有缺失
- [ ] 没有重复同一信息的镜头
- [ ] 观众问题被正确延迟和回答
- [ ] 节奏有疏密变化
- [ ] 情绪曲线逐步推进

### 常见问题：只有动作，没有反应

症状：事件发生了，但观众不知道它意味着什么。

修复：补 Reaction / Aftermath。反应镜头可以是表情、停顿、身体退缩、道具掉落、环境静止等。

## 4. 空间与连续性质量闸门

检查：

- [ ] Floor plan 已明确角色、道具、机位、轴线
- [ ] 轴线清楚，越轴有设计理由
- [ ] 屏幕方向连续
- [ ] 角色视线方向连续
- [ ] 制作层入口 / 出口 / 移动路线成立；观众层按本时点应知检查
- [ ] POV 与客观镜头关系清楚
- [ ] 已区分无意混乱与有意暂未知；后续需地理判断前有重定位线索，抽象作品可声明持续未知

### 常见问题：空间混乱

症状：角色位置跳变、方向反了、越轴无意图。

修复：先核是否有意平面/有限/暧昧空间。无意跳变才回俯视图、轴线与可用机位；需重新定位时可用地标、边界、连续视差、声音或建立镜头，不强制全景，也不破坏已选长镜头。详见 visual-structure-and-space.md。

## 5. 剪辑质量闸门

使用 Rule of Six：

```text
情绪 > 故事 > 节奏 > 眼迹 > 二维平面 > 三维空间
```

检查：

- [ ] 切点是否符合情绪
- [ ] 切点是否推进故事
- [ ] 节奏是否正确
- [ ] 观众眼睛是否在切前切后落在可控位置
- [ ] 二维画面是否产生跳跃
- [ ] 本时点必须理解的空间关系是否清楚，允许未知是否有明确范围

### 常见问题：技术连续但情绪不对

症状：轴线和动作都接上了，但观众情绪断掉。

修复：情绪优先。调整切点到角色思考、意识变化、动作冲动或观众问题发生的位置。

## 6. Timing / Animatic 质量闸门

检查：

- [ ] 每格时长已估算
- [ ] Hold 给观众足够阅读时间
- [ ] Anticipation 提前引导眼睛
- [ ] 动作有重量、惯性、重叠
- [ ] 节奏有快慢变化
- [ ] 台词、音效、动作点同步
- [ ] 情绪点有停顿或加速支持

### 常见问题：节奏匀速

症状：每个镜头时长差不多，动作像幻灯片。

修复：

```text
重要信息前给 anticipation；
重要情绪后给 hold；
喜剧或冲击点用 accent；
动作过程用 slow in / slow out；
删掉没有变化的中间段。
```

## 7. 动画交付质量闸门

进入 animation 前，每个动作镜头至少标出：

```text
Key pose
Extreme pose
Breakdown
Anticipation
Follow-through
Overlap
Weight
Spacing
Facial change
Eye direction
Hand / prop action
```

### 常见问题：分镜不接动画

症状：只画动作结果，没有准备、过程、重量和恢复。

修复：把动作拆为 Anticipation / Action / Reaction / Aftermath，并标 key / extreme / breakdown。

## 8. 跨镜组／跨场接口质量闸门

当序列被拆成多个 DO、Clip 或生成批次时，不能只逐镜检查；必须对相邻组执行一次“尾帧 → 起点 → 首个新事件”的接口审计：

- [ ] 下一组从上一组的已完成结果起步，不重演转身、上肩、入场、汇合、停步或声音启动
- [ ] 若中间过程被省略，组头明确“时间已推进／画外动作已完成／从既成状态开始”
- [ ] 上一镜的声音、背景轮廓、参考素材或摄影机边缘没有提前泄露下一组才应揭示的人物、空间或动作
- [ ] 过渡方向只建立抽象路线时，不提前展示下一地点本体；例如只交代“下游方向”，把“小桥”留给切后揭示
- [ ] 每镜可见主体白名单与组头人口一致；“背景居民不参与”和“背景不出现居民”不得混用
- [ ] 组头、逐镜正文、尾帧表、限制项和联合验证中的旧状态已同步清除

### 声音提前泄露不是自动加分

J-cut 只有在“先听见”本身承担悬念、辨认或空间接力时才使用。若当前镜的结果尚未停稳，下一动作的声音会抢走注意力，应改为：

```text
当前结果完成并停稳
→ 硬切／明确切点
→ 切后才建立下一主体已经站稳并开始动作的状态
```

### 人口描述必须使用同一强度

```text
允许远处不可辨识轮廓 ≠ 不出现居民
只保留生活声 ≠ 允许生成背景人物
```

先在组头确定可见主体白名单，再逐镜复述必要成员；发现强度冲突时，以更明确的白名单重写，而不是保留模糊折中措辞。

## 9. 最小通过标准

时间很短时，至少检查 7 个问题：

```text
1. 这个镜头让观众看哪里？
2. 这个镜头回答或制造什么问题？
3. 角色此刻想要什么？
4. 这个镜头之后信息或情绪有什么变化？
5. 观众是否知道本时点必需的主体/空间关系，允许未知是否受控？
6. 切到下一镜头时眼睛是否接得上？
7. 这个动作的 timing 是否能被动画执行？
```

任意问题答不上来，先修复再扩展镜头数量。
