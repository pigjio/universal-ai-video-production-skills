# 七要素视觉结构与空间显隐

用于讨论、探索和序列设计；不以完整表格或母版作为讨论门槛。来源为蒸馏稿的二次转译，精确章节见 `source-map.md`；以下案例不是测试结果。

## 1. 从七要素选主导结构，而非七项齐变

**触发**：频繁换景别仍平、长镜头缺变化、非叙事作品需要组织体验、希望有意维持低强度。
**证据**：当前序列/文字草稿、目标体验及转折、已定空间与媒介、需要保持的节律。没有图像只做设计推演。

| 要素 | 可观察量 | 可比较的处理 |
|---|---|---|
| 空间 | 汇聚、层数、尺度差、视差、可辨识程度 | 深与平、层次与暧昧的转换 |
| 线 | 主导方向、边缘、视线连线、运动轨迹 | 同向重复与方向冲突 |
| 形 | 大形、剪影、形状重复和差异 | 同类形维持与异形闯入 |
| 明度 | 大块比例、局部对比、可见边缘 | 近似灰阶与局部反转 |
| 色彩 | 色域、彩度、面积、重现意义 | 同色持续与局部异色；黑白可不启用色相 |
| 运动 | 主体/摄影机/眼迹方向、速度与停顿 | 静观、平行运动、纵深运动或视差 |
| 节奏 | 静态排列间隔、重复、停留、视觉重音、切点 | 匀速仪式感、疏密变化、断裂 |

执行：①先写段落希望发生的观看变化；②从七要素选主导变量，列其余保持项；③按段落排“起始→偏离→结束”，不固定高潮曲线；④区分**镜内对比**（同帧差异、长镜头内变化）与**镜间对比**（相邻画面关系）；⑤缩成线形/明暗小稿或粗略时间序列，比较强度和信息得失。只有需要时间证据才做 Animatic。

竞争解释：节奏平可能是切点匀速，也可能是各镜主导方向、明度和空间关系完全同质；只缩时长会使误读更快。反过来，有功能的重复可能正是意图，不能自动添加高潮。高对比不是质量分，形式强度不必与剧情强度同升同降。

**演练**：无人物黑白窗帘长镜头。A 以明度面积主导，布边逐渐遮光又释放，其余机位、色域不变；B 以节奏主导，遮光面积相近但间隔由规律变稀疏。A 更直接显示空间收缩，B 更突出等待；代价分别是可能过于解释环境、难以辨识变化。可先比较整组方案，再在选中方向内定位读取问题，不要求七项全变或自动切近景。
**边界**：色彩不使用红=危险等跨项目硬译码；线形情绪须由本片语境支持。纯概念循环可不设不可逆结局。

## 2. 空间成立与观众知情分开

**触发**：用户要长镜头并暂藏地理，或“平面感”可能是有意设计。
**证据**：制作层可用边界/合成关系、观众当前应知、允许未知、后续行动依赖，实际深度线索。

- **深空间**：汇聚、尺寸变化、纵深运动、视差等利于读路线，代价是层次竞争。
- **平面空间**：正面平面、相近尺寸/纹理、平行运动减少纵深，利于图案化和舞台感，代价是距离难判断。
- **有限空间**：少量正面层以遮挡/明度区分、少汇聚与穿深运动，层次明确但不强调连续纵深；跨层接触需额外证据。
- **暧昧空间**：隐藏尺度、镜像、极端裁切或明暗伪装，推迟识别；这是辨识程度，可叠加上述结构。代价是可能让应知关系也丢失。

先区分意图还是失误，再选修复。制作层记录足够执行的空间，不代表观众须先看全景。观众层写：现在必须知道什么｜暂未知什么｜什么时候以尺度物、边界、连续视差、声音位置或明确省略重定位。抽象作品可保持未知至结束，只要不依赖未解释的具象地理完成因果。

**演练**：镜头贴近亮纹，暂不知是天窗还是水面；缓慢横移露出固定窗框与倒影破碎，才给“这是水”的线索。保留长镜头，明度与运动承担揭示，不插强制建立镜头。若后续要判断物体是否能通过窗口，必须在该判断前提供尺寸/边界；不能用“暧昧”掩饰不可达路径。
**回归**：只核本时点应知信息；未看图不声称观众已理解。静态画不证明运动和视差已经成立。

## 3. 同一事件的构图关系语气与光色接力

**触发**：看懂事件却读不出压力落点，或场景光色漂亮但提前泄露证据。
**证据**：事件保持项、环境/人物面积、关键点距离、留白、遮挡、光源和材质条件、前后镜信息边界。

比较候选时写“谁占画面、谁被挤压、谁能看见谁、观众得到/失去什么”，不只换角度标签。环境占画面可形成压力，也可表达开阔；斜线可能优雅，非必然紧张。光色卡写“现象条件→可见效果→应知/暂隐藏→下镜继承”。物理可信与信息功能分开检查，光源合理不代表焦点正确。

**演练**：同一人伸手碰门把。A 近处读清手部，门外空间画外，保留未知；B 让墙与门占大面积、脸处暗，压力转到房间，但接触证据较小。B 可在手触时让局部反光显出把手边缘，下镜继承门已被触碰，而不是重演伸手。若反光提前暴露门后人影，则降反射、换允许机位或延后光域；每项都有损失，不用“更电影感”回避比较。
**边界**：不能为了悬念删掉后续理解必需的因果；匿名剪影可以不读脸。跨镜继承须解释光域/遮挡变化，不靠无来源的换色。场景物理细化交场景光色方法，分镜负责出现时机。

## 4. 固定与运动不是按位移分工

触发：没有主体位移却想运镜。比较固定（利于稳定读取/疏离观察）与推拉、横移、环绕（可改变关系、视差、尺度或主观接近）。先列观看收益，再核代价：运动会泄露空间、分散细微表演或增加制作风险。
演练：人物不动，慢退露出一直在旁的空座位，关系发生变化；固定近景则保留孤独的解释开放。选择依意图，不以“人没走所以不能动镜”否决。若退镜无新增感知作用且抢表情，保留固定或延后移动。探索可整组比较，诊断再隔离变量；约束越界先请裁决。
