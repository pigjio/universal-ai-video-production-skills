# 并行事件时间、情绪继承与信息负载

适用：交叉剪辑中威胁像在等待、画外动作被暂停、反应镜表情重置，或动作完整却难以读取。以下是条件性诊断，不强制角色、威胁或固定镜数；无角色项目只检查事件与感知连续性。

## 1. 分开两套时间

1. 银幕时间记录镜头在成片中的起止；故事事件时间记录同一世界内各事件何时发生，另标省略、重叠回看或主观时间。
2. 对每条并行事件建立 `事件ID → 起始条件 → 不可撤回运动启动 → 路径/阻滞 → 接触 → 结果`，记录画外仍在推进的阶段；一镜可跨多个阶段，不得无原因倒退或冻结。
3. 将感知、准备、应对形成、动作生效放到同一事件时间轴；比较应对完成是否早于接触。距离、速度未知时标估计及待验证，不编精确物理结论。
4. 并行准备不机械相加；存在依赖的步骤才顺序累计。片长统计仍按银幕轨道处理，算术与编号加载 `references/timing-verification.md`（相对技能根目录）。

失败分支：若威胁已启动而应对来不及，选择延后启动、提前准备、真正并行、加入可见阻滞或缩短可压缩动作。慢动作须明确建立主观时间及恢复点，不作为隐藏补丁。距离、阻力或阻挡的规则须在生效前成立，不能临时添加出口或受力路径。

判断示例：交替展示坠落物与角色取防护物时，取物镜不意味着坠落停止；先排事件轴。若接触早于防护就位，修准备时机或建立阻滞，不能仅把标题秒数调短并宣布通过。

## 2. 情绪作为跨镜状态

记录 `输入情绪 → 可见/可听触发（或已声明省略）→ 表演变化 → 输出情绪 → 下一行动`。相邻反应镜继承输出，不重新随机选择表情；同镜可发生多个清楚可读的变化，不限固定数量。

- 通过视线、呼吸、姿态、动作节奏与面部共同证明；矛盾信号若为克制或伪装，应明确意图。
- 记忆或物件插入须说明认知增量；只有需要观众看见推理过程时才交替回到反应，不强制固定“脸—物—脸”格式。
- 决定后的行动须兑现已建立意图；若改变意图，补足触发。跨生成批次也检查情绪、姿态、道具与事件阶段，不因分批重置。

判断示例：受挫后直接切坚定表情，但无新证据、内在决意的表演或时间省略，标为继承断裂；可补一个可读的重整动作，或保留受挫状态让行动先体现勉强坚持，不必机械增加特写。

## 3. 信息增量与负载决策

为每镜写“观众进入时已知什么／离开时新增或改变什么／需要读取哪些线索”。增量包括证据、空间关系、期待、情绪和感知节律，不等于必须增加事件。

- **低增量、低负载**：做删镜测试；若理解、情绪与节律均不受损则合并，否则保留其功能。
- **高增量、高负载**：先分清主次焦点，检查陌生信息、动作相位、字幕、声音是否互抢；可简化、延长、分层揭示或拆镜，不只增加镜数。
- **低增量、高负载**：优先删重复证明与装饰性运动，而不是砍关键反应。
- **静止或慢镜**：若期待、关系或形式感知仍在变化，属于有效停留；无法说出变化时再查冗余。

判断示例：门缝新线索、人物转头和字幕解释同时争焦点，可先让声音引导视线，再揭线索，最后读取反应；若同镜调度已经清晰，无须按三个事件拆三镜。

## 4. 完成与交接

使用正文公共头，payload 附银幕/事件时间对应表、各事件阶段、情绪输入输出、信息增量、负载风险及修复理由。通过条件：事件没有无说明暂停或回滚；情绪改变有依据；关键线索可读取；后镜继承实际完成状态。文本可自洽不等于成片通过；有 Animatic 才记录实际观察范围，无文件标未测试。
