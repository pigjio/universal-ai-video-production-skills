# 图像与视频提示词

先读取 [使用约定](references/usage-rules.md)。

静态角色概念遵守 [角色](../ai-character-design/SKILL.md)，静态场景概念遵守 [场景](../ai-scene-design/SKILL.md)。静态图不添加视频时间轴或声音要求。

## Seedance 视频输出

按当前分镜展开，不在提示词中擅自改剧情、角色或镜头安排。参考素材只写实际已有及实际上传的状态，不编造 @句柄。必要的上传说明、平台设置和未核验事项放在代码块外。

每个生成请求给一个独立可复制代码块，直接从镜头编号开始。若一个请求包含多个镜头，每镜完整展开字段，不写“同上”；不同请求也必须独立说明必要身份、场景与状态。用户没有要求合并时优先逐镜交付。

使用 [中文／韩文视频模板](references/video-template.md)，标题和具体内容都放在代码块中。不得添加“请求标识、画幅与视觉风格、生成时长、参考素材与职责、主体与场景”这五个顶层字段；必要信息分别融入画面构图、起始状态或块外说明。

每个代码块最后一个非空行必须是中文“无背景音乐”，包括韩文输出。保留对白、音效和环境声；不得同时要求背景配乐。它是提示词要求，不是平台效果保证。

交付时填实所有字段，无人物时写主体变化，不适用项简述原因；未知平台能力标待核验，不用编造参数补齐。对白保留原文、说话者和语言，声音与口型是否可生成需核验，必要时提出后期方案。

保持镜头编号唯一、目标时长与时间轴相容、结束状态与下镜起点一致。时长为估计时明确说明。提示词完成只能称“请求稿完成”，不得称已生成或已通过视频评审。
