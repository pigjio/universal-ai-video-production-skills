# 声音、对白与口型交接

在有对白、画外声揭示、声音桥、沉默转折、音乐竞争或可见口型时加载。无声作品不强补音轨；“无对白”也不自动等于“所有声音静音”。内部细项按需维护，学生只需选择表达效果。

## 1. 先确定声音在叙事中做什么

对白可以试探、安抚、隐瞒或改变对方行动；环境声建立场所与距离；动作声证明接触或状态；声音先行可把注意力引向尚未看见的空间。音乐可以组织情绪/节奏，也可能提前泄露信息、盖住关键台词或让克制表演过度煽情。

对每个关键声响先问：声源是谁/什么、谁能听见、观众何时听见、听后发生什么变化。声音存在于观众音轨，不代表角色听得到。不要让配乐或旁白无意中给角色传递剧情信息。

| 类别 | 记录重点 | 常见混淆 |
|---|---|---|
| 画内对白 | 发声角色、逐字文本、语言、可见嘴部、听者反应 | 嘴动的人与台词归属不一致 |
| 同场画外对白/声响 | 实际声源、位置、传播/遮挡、谁能听见 | 把离开画面误写成离开现场 |
| 旁白/内心独白 | 叙述主体、时间关系、是否为故事内声音 | 自动让画面人物同步张口，或让其他角色听见内心独白 |
| 动作/环境声 | 动作触发点、空间距离、连续或中断 | 声音先于接触却被写成同步声，切镜后环境底噪凭空改变 |
| 沉默 | 只停对白、音乐退去，还是有意全静音 | “安静”被当成删掉全部环境声 |

## 2. 表演与声音共同设计

同一句“你走吧”可执行放行、试探或赶走。先根据剧情选择意图，再写语气与停顿；不要把“低沉、有感情”当完整表演。听者的动作改变可能比说话者正面口型更重要，分镜可在台词中切到听者，但要维持发声归属、空间和连续音轨。

改拍听者时核对画外说话者仍在做什么。若其动作末态决定下一镜，独立请求也要交代该同场画外动作、完成点及尾态，并写明摄影机不为它切回。画外动作是连续性约束，不是要求模型展示被保护的口部；下一镜再显露结果时不要重演。

声音桥是有意义的时序关系：下场声音提前进入当前画面，或前场声音延续到后场画面。标注源场、进入点、退出点和观众得到的信息；不能以“声音桥”掩盖故事时间冲突。

## 3. 最小内部声音记录

只给需要精确交接的声响稳定 ID，可放在已有分镜或请求 payload 的 `audio_cues`，不新增强制公共头字段：

```text
AU01 / 对应 SH02、SH03
声源：同伴；同场画外对白；她能听见
原文：你走吧。 / 语言：普通话
意图：放行，不追加解释性台词
进入：她看向门口时；退出：看向袖口前
可见嘴部：SH02 可见，SH03 仅听者可见
时间：读演前为估计；停顿与听者反应另留空间
执行：生成音轨或后期配音待选；当前入口口型能力待核
验收：说话者正确、文字未改、触发顺序正确、听者不跟着张口
```

内部 ID 不必粘进平台文本；复制块必须展开真实发声者、具体台词、动作触发和声音要求，不能只写“按 AU01”。

## 4. 中韩对白与计时

- 保留原文、目标语言及角色关系；中韩不是逐字替换，敬语/半语会改变关系。未知关系可暂定说明，只在影响台词时问一个问题。
- 翻译不得自行改变说话者、秘密揭示、请求/命令性质或角色选择；变化需回到剧本确认。
- 不用统一每秒字数/音节数宣称精确时长。先按目标语言读演或取得授权音频样本，再记录实际测量与停顿；没有音频只能标估时。
- 台词、观察、反应和接触可部分重叠，但不能让关键信息竞争到不可读；过长时比较删冗词、延长/拆分、改变覆盖，不能静默加速或删情节。

## 5. 平台执行分支

本包视频提示词不要求背景配乐；每个独立复制块最后一个非空行固定写“无背景音乐”，韩文稿也保留该中文原文。对白、动作音效和环境声仍按需要保留，不能将此规则解释为全部静音。上述音乐理论用于理解声音取舍，不授权在提交正文中加入相冲突的配乐要求。固定末行是文本约束，不代表已经听检真实结果。

声音生成、参考音频、特定语言、口型同步、后期配音是不同能力。按实际模型、产品入口、模式、官方来源与核验日期分别确认；文档支持不证明当前结果自然。

1. 已核验支持且获执行授权：记录输入音频职责、台词、语言、可见口部与同步要求；实际生成后检查归属、遗漏/增词、口型与动作。
2. 支持未知：仍给视频候选文本和独立声音说明，标记音频/口型待核验，不承诺一键完成，也不把目标音轨说成已生成。
3. 用户选择后期配音：记录对白与动作锚点、环境/动作声、混音优先级。若嘴部清晰可见，普通配音不自动解决口型；需匹配读演/口型工具或经确认改为听者、背面、遮挡覆盖。

后期覆盖改变机位、观看重点或关键动作可见性时，先回分镜提案。不得为了绕开口型问题擅自把面对面告白改成旁白。

## 6. 审查出口

只有截图时，声音、音画同步、整段台词和节奏均为 unconfirmable。只有音频可以查听到的词与时长，不能证明画面中是谁张口。完整视听检查才可覆盖同步；实际观众理解与人工接受仍需真实反馈。

## 来源边界

叙事判断复用《Dialogue》蒸馏的语言行动、潜台词、沉默与角色声音，以及《Film Directing Shot by Shot》蒸馏的声音预演、对话调度、反应覆盖。声轨字段、语言计时、口型分支属于本包工程交接综合；不是书籍提出的 Seedance 功能。尚未补入或核验专门声音设计/混音著作，不把本参考称为完整声音理论库。
