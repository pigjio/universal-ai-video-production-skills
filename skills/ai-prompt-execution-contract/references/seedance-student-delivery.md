# 面向创作者的 Seedance 可复制交付

当用户要“给我能直接复制到 Seedance / 即梦的提示词”时，先在后台完成正式合同检查，再把用户需要操作的内容放在最前。不要要求用户阅读公共 YAML、理论术语或内部审核表。

## 默认交付顺序

````markdown
# Seedance 视频提示词

## 使用说明
- 本次共 N 次生成；每段对应哪些分镜。
- 使用文生视频、图生视频、首尾帧或多参考中的哪一种；能力未核验则明确待确认。
- 先上传哪些素材；没有真实平台句柄时不要伪造 @引用。

## 参考素材绑定
| 素材 | 负责锁定 | 不要继承 |
|---|---|---|

## 镜头 01｜可直接复制
```text
[独立、自包含的平台提交文本]
```

## 镜头 02｜可直接复制
```text
[独立、自包含的平台提交文本]
```

## 连续生成与尾帧接力
- 上一段必须实际返回并检查什么。
- 下一段从哪个可见状态开始。
- 没有真实尾帧时提供文字重建方案，不虚构已经提取。

## 生成失败时优先修改什么
1. 先核实际上传素材和起点是否冲突。
2. 再减少同一请求中的主体、动作阶段或摄影机负荷。
3. 只改一个主要问题簇；保护已通过镜头。
4. 必须改变景别、机位、镜头数、Reaction 或首次揭示时退回分镜。
````

## 单段提示词的最小骨架

按自然语言组织，不要求把字段名原样粘进平台；但每段必须能回答：

```text
目标：本段只完成什么可观察变化
资产：实际上传的角色、场景、道具及各自职责
起点：承接的姿势、位置、持有物、损坏和光线
空间：左右、距离、朝向、尺度、入口与支撑面
摄影：景别、焦段倾向、机位、唯一主要运镜与停稳
时间轴：触发 → 路径/接触 → 反馈 → 结果 → 必要停留
物理：重心、受力、遮挡、碰撞、材质反应
声音：对白、动作声和底噪绑定到具体节拍；不需要可省略
终点：可见、稳定、可作为剪辑点或续接起点的末态
禁止：只列最高风险的身份、数量、方向、穿透或新增事件错误
```

## 从已确认分镜展开

- 保留镜头 ID、任务、景别、机位、动作、时长和末态，不在平台稿中改写剧情。
- 一个分镜不必等于一次生成；多个镜头可在能力允许且任务统一时合并，一个复杂镜头也可按状态边界拆为多次生成。
- 每次生成只有一个主要任务和一个可观察完成判据。若用户说“镜头太碎”，先回分镜比较合并代价，不直接把所有镜头塞进一个长提示词。
- 参考素材只写真实上传项。计划上传、仅存在于本地或尚未观察的文件不得写成已绑定资产。

## 简短原创例

分镜依据：固定中景里，A 把钥匙交给 B；关键结果是钥匙完全离开 A 的手并稳定落入 B 掌心。

可复制文本应明确 A/B 左右位置、钥匙起点、伸手路径、交接接触、放手反馈、B 握稳后的停留、固定机位和禁止换手；不新增环绕镜头、掉落钥匙或第三人。若参考图未实际上传，就用身份描述并把精确复现列为待验证，不编造 `@角色A`。

## 诚实的完成声明

提示词与结构检查通过，只能说“可复制请求稿已完成”。未实际提交时不能说已上传，未取得任务回执时不能说已生成，未观看视频时不能给时间码或声画通过结论。平台限制随模型和入口变化，固定秒数、素材数和声音能力必须现场核验。
