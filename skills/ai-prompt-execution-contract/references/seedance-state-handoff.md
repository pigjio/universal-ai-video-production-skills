# Seedance 状态接力与续接接口

## 适用条件

当相邻生成请求需要继承人物、物体、空间、动作相位、光色或声音状态时加载。没有真实依赖时不为形式完整强造尾帧字段。

## 1. 四种接口来源

| source | 适用条件 | 最低证据 | 禁止行为 |
|---|---|---|---|
| `real_tail_frame` | 上游真实视频可访问，末段经连续观察合格 | 原片 ID/版本、时间码、邻近观察区间、提取文件、上传回执 | 用单帧推断速度；传播错误尾帧 |
| `textual_reconstruction` | 尾帧漂移、未获上传授权或无需像素连续，但导演起点明确 | 状态来源、已知/未知项、下一镜建立方式 | 称像素级续接或伪装成上传图片 |
| `independent_restart` | 下游可从权威角色/场景/道具基线独立建立 | 重新绑定素材、目标起点、与上游剪辑关系 | 暗称继承了上游生成身份 |
| `verified_context` | 平台确有可验证会话/资源上下文继承 | 上下文/资源 ID、能力证据、实际绑定记录 | 只写“沿用上一段”却无平台证据 |
| `none` | 无跨请求状态依赖 | 明确无接口职责即可 | 填造假的尾帧或上传状态 |

## 2. 文字接口的最小字段

按适用性填写，不强迫抽象视频填写左右手或地面：

```yaml
continuation_interface:
  source: textual_reconstruction
  source_evidence: null
  known_state:
    space_anchor: null
    camera_orientation: null
    subjects: []       # 位置、朝向、重心、遮挡、视线
    holdings: []       # 左右手/握点/数量/状态，仅适用时
    support_contacts: []
    motion_phase: []   # 静止/启动/进行中/完成，方向与速度范围
    material_and_light: []
    environment_state: []
    audio_tail: null
  completed_actions: []
  actions_not_yet_started: []
  unknowns: []
  next_request_first_shot_obligations: []
```

下一请求第一镜必须建立这些既成状态，并继续未完成动作；不得重演 `completed_actions`。

## 3. 真实尾帧验收

不能只看最后一帧截图。连续观看末段并检查：

- 身份和数量是否稳定；
- 空间地标、支撑面和刚性几何是否正确；
- 世界方向、屏幕方向、左右手和道具状态是否正确；
- 运动方向、速度范围和动作相位是否可继承；
- 末镜是否仍在重构、遮挡或剧烈运镜；
- 光色与材质是否为下一段合法起点；
- 声音尾音是否需要延续。

任何会污染下游的身份、几何、方向、道具或空间错误，都使 `eligible_for_reuse: false`。可选回退：上游局部重生成、使用稍早的合格切点、经授权桥接，或文字/独立重启。

## 4. 领随运动与多人接口

若多主体持续运动，接口不能只记录一个人的落脚：

- 谁先启动；
- 谁持续领先；
- 当前领先距离；
- 每个主体处于动作周期的哪个相位；
- 摄影机跟随对象；
- 脚步/动作声的起声顺序；
- 下一镜谁先入画或先出画。

否则模型容易让跟随者先冲出、人物换位或全部从静止重新启动。

## 5. 反向机位和遮挡桥

后方跟拍切到正面迎拍时，遮挡换机位可作为候选：主体继续运动，近景遮挡物完全覆盖画面后切换机位，再按原领先关系进入新构图。它不是通用强制语法；只有当空间、轴线和导演意图允许时使用。

## 6. 验收

- 接口来源真实且证据层级明确；
- 已完成与未开始动作分开；
- 下一请求首镜逐项承接，没有重演；
- 文字重建没有冒充真实媒体；
- 坏尾帧已阻断下游；
- 没有真实依赖时接口被省略。
