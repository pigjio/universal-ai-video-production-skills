# 类型惯例、观众承诺与短片压缩

类型不是题材标签，而是作品持续施加压力、控制信息并兑现观众期待的机制。本参考帮助 Agent 在后台判断“这故事答应了观众什么”，不把用户变成类型理论学生。

> 来源边界：直接覆盖最强的是 Save the Cat 十种故事机制、喜剧、悬念与冲突、反派、冒险成长、个体与制度、超常人物。爱情、犯罪、恐怖等传统标签可作为跨书综合的观众承诺使用，但不宣称已经形成完整类型史或穷尽其全部惯例。

## 每个类型判断必须包含什么

```text
核心压力机制：故事用什么压力反复逼迫选择
观众期待：观众进入作品后合理等待什么体验
基本故事问题：结尾必须回答或有意保持开放的核心问题
必须兑现的场面功能：不是固定桥段，而是必须被看见的功能
升级方式：时间、信息、选择、关系、资源或规则怎样收紧
隐藏与揭示：谁先知道什么，何时改变观众问题
高潮机制：最终行动如何检验故事承诺
常见俗套：最容易自动生成的熟路
可替代反转：改变因果或立场，不只隐藏身份
短片压缩：保留哪三到五个功能节点
适用边界：何时换类型或只作为副类型
```

## 高价值类型机制包

| 机制包 | 观众期待与基本问题 | 必须兑现的功能 | 升级与高潮 | 常见俗套 / 反转方向 |
|---|---|---|---|---|
| 困境中的人 | 普通能力面对异常压力；“他能否在规则收紧前找到活路？” | 清楚的日常基准、异常规则、首次有效尝试、代价 | 减少安全选项；高潮用先前建立的能力作真实选择 | 俗套：突然获得万能能力。反转：活路一直存在，但会伤害他要保护的人 |
| 远征与成长 | 外部目标改变人物理解；“得到目标后，他成为什么人？” | 出发理由、代价递增的路标、一次价值冲突、回返或新平衡 | 每个路标改变策略或关系；高潮让外部目标与价值不能兼得 | 俗套：旅行蒙太奇等于成长。反转：终点物已失去，真正选择发生在回程 |
| 个体对制度 | 人与更大规则系统摩擦；“改变系统、逃离它，还是被它同化？” | 制度如何日常运作、妥协收益、反抗代价、系统反应 | 从个人阻碍升到关系/身份成本；高潮必须让立场变成行动 | 俗套：一个演说推翻系统。反转：小胜保住具体的人，但制度仍在 |
| 超常人物 | 非凡能力与日常限制的反差；“能力解决问题时又制造什么？” | 能力边界、误用后果、不能靠能力解决的关系或价值问题 | 敌手利用边界；高潮不是临时升级，而是重新选择能力用途 | 俗套：更大能量束取胜。反转：主动不用能力才完成目标 |
| 悬念 / 秘密 | 信息差制造可预期危险；“威胁何时抵达，谁先发现？” | 威胁证据、有限视点、误判成本、发现后的选择 | 缩短时间并改变已知信息；高潮兑现早期线索 | 俗套：全靠任意遮瞒。反转：观众早知真相，悬念转为人物何时承认 |
| 喜剧压力 | 严肃目标与偏斜策略持续碰撞；“错误模式会如何升级？” | 清楚预期、重复规则、变化一次条件、反应与停顿 | 增加社会代价或让模式反咬；高潮把笑点变成真实选择 | 俗套：角色突然变笨。反转：最荒谬策略意外有效，但暴露更大问题 |
| 对抗型反派 | 对手主动攻击主角的策略或弱点；“谁能迫使谁改变计划？” | 对手合理目标、优势、升级、至少一次有效反击 | 对手学习并缩小主角选项；高潮双方策略正面相撞 | 俗套：反派只等主角来。反转：对手说对了问题，却选择了不可接受的手段 |
| 关系 / 爱情（有限覆盖） | 两人能否建立互惠关系而不牺牲核心边界 | 相互吸引或需要、价值摩擦、真实脆弱、一次有代价的互相选择 | 外部压力揭示关系策略；高潮以行动确认靠近、分开或重新协商 | 俗套：误会靠不沟通维持。反转：秘密早已知道，冲突来自如何共同承担 |
| 犯罪 / 追查（有限覆盖） | 行为、证据与代价能否形成公平因果 | 犯罪或异常后果、可读线索、竞争解释、发现改变行动 | 线索压缩嫌疑与选择；高潮同时回应事实和人物代价 | 俗套：最后引入无铺垫真凶。反转：事实早清楚，真正谜题是为何所有人保持沉默 |

## 混合类型规则

只选一个主压力机制，副类型负责语气、关系或局部信息组织。若两个类型要求不同高潮，先问用户更希望最后满足哪一种期待。例如“爱情 + 悬念”可由悬念控制信息，但高潮仍以关系选择收束；若最终只揭示凶手，爱情就是副线而非主类型。

## 短片压缩

短片不等于把长片节拍全部缩短。至少保留：基准与承诺 → 压力第一次改变策略 → 一次不可忽略的代价或信息变化 → 高潮选择 → 可见新状态。可合并角色和地点，但不能删掉使高潮成为真实选择的证据。

## 讨论输出

面对“太普通”，不要只加反转。先给不超过三种差异明确的诊断：类型承诺没有兑现、压力机制重复、人物选择可被任何人替代。每种给一个局部改法与代价，用户选择后只改受影响内容。
