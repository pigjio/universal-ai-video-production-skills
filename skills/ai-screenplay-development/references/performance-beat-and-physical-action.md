# 表演节拍：从意图到可见行动

在“人物很僵”“情绪不可信”“只剩表情标签”、无对白决定或潜台词场景中使用。目标是让观众看见人物如何回应具体处境，不是给每种情绪配一个固定动作。普通场景只用必要判断，不要求学生填表。

## 1. 先找人物正在对谁做什么

区分三层：

- 当下目标：希望对方留下、交出物件、停止追问，或自己完成某项可观察任务。
- 行动策略：试探、安抚、回避、遮掩、请求、挑战；策略是否奏效由对方或环境的反馈证明。
- 身体活动：收拾、倒水、扣袖口。活动只有和目标、反馈相连，才承担戏剧行动；不要为了“丰富表演”随机加摸脸、踱步和叹气。

写出最短的“刺激 → 接收到什么 → 尝试 → 反馈 → 调整/保持 → 结果”。不是每段都要换策略：坚持、僵住、克制、等待也可成立，但应有情境依据。突发动作可压缩反应过程，不能抹掉关键决定的触发。

## 2. 可见证据的选择，不是情绪词典

| 需要观众读懂的变化 | 可选择的证据 | 何时不适用 |
|---|---|---|
| 注意转移 | 视线落点、停下原任务、头与身体先后转向 | 角色尚未看到/听到触发，不能提前反应 |
| 隐藏意图 | 话语继续而手停住、礼貌呈现与动作残留不一致 | 不知道隐藏对象与理由时，不自动添加潜台词 |
| 重新选择 | 松开门把、放下行李、把物件推回、重新靠近 | 这些只是候选，不能擅改已确认剧情 |
| 力量/接触变化 | 发力来源、重心、支撑、接触与释放 | 抽象主体或超现实机制不强套人体运动 |
| 关系变化 | 距离、朝向、谁先接触、谁让出行动空间 | 不把靠近一律读作爱、后退一律读作恐惧 |

先选一两条能在当前景别读到的线索。远景优先姿态、距离和动作中断；近景才考虑微小眉眼变化。没有读到情境时，“悲伤=低头”“紧张=发抖”只是套话。脸、身体和台词可以有意不一致，不用“统一情绪”消灭压抑表演。

角色结构、习惯脸与即时表情的区别，以及 Force/重心、复合表情测试，复用角色阶段的[表演与生产验证](../../ai-character-design/references/performance-and-production.md)，通过 `ai-character-design` 路由读取；不在剧本中重建完整角色表情库。

## 3. 三阶段的职责

- 剧本：写目标、反馈和发生的行动，保留潜台词；不把每个眼睑角度锁死。
- 分镜：决定观众看哪条证据、在什么尺度看到、何时切走；一个表演节拍不必单独成镜。
- 提示词：把已经选择的行动按顺序写出起点、触发、动作和结束状态；内部动机不能替代可执行描述。

镜头切换时继承未完成的动作与情绪残留，不让每镜从 neutral 重新开始。明确时间省略可以改变状态，但要让观众能理解省略。

## 4. 原创例：离开前停住

原始任务：她准备离开，看见同伴扣袖口失败，决定主动回来帮忙。不能用“她感动了”代替决定。

可演版本：她握着行李，目光落在门口。同伴再次捏住扣子，却没能穿过扣眼。她停下，视线落到那只手；行李落地后，她才松开提手，返回同伴身边。同伴不再抢着扣，让出袖口。

判断：刺激是看见困难；放下行李使“留下”可读；让出袖口是接受帮助，不必解释全部关系。若原稿要表现控制而非关心，主动接手可能有不同意义，须重新选择反应，不能套用温情版本。

连续性：看见困难在选择之前；行李保持在门边；帮助由她发起。若改为同伴请求帮助，人物主动性的含义发生变化，应退回剧本裁决。

## 5. 修复与边界

- 太僵：先查有没有目标、反馈和可见差量，再查身体同相位/接触，不先堆微表情。
- 太夸张：减弱重复证明，保留改变策略的一瞬，而不是抹平所有反应。
- 太慢：删已读懂的重复和无功能等待，不删首次触发和主动选择。
- 无人物：改用材料响应、观看变化与前后状态；不强补心理、表演节拍或角色。
- 只有文本：只能判断设计意图是否可读；没有试演、Animatic 或真实视频，不能宣布表演验证通过。
