# 分层诊断与旧稿功能迁移

用于局部不成立、压缩损失互动或恢复旧稿丰富度。旧稿是功能材料，不是现行事实依据；未请求不反向同步分镜、Clip 或 Prompt。

## 诊断步骤
1. 确认请求范围、当前批准版本与相邻场。列当前不可改事实：地点、时点、能力、道具、损坏、知情、母题权限。
2. 按最小失效层定位，引用具体句/场号与缺失证据，写修复假设，不用“更电影感”代替诊断。
3. 故障诊断优先选一个主层便于归因，说明哪些层保持不动；开放探索可联动多层并说明收益代价。先重建完整表演/观看过程，再做时长压缩。
4. 对新稿跑邻场输入输出、真实选项、知情和规则校验；保存版本及改动理由，交人工审阅。

| 层级 | 诊断问题 | 最小修复/回退 |
|---|---|---|
| 前提 | 核心承诺与结尾是否不同题 | 先澄清承诺，不先润台词 |
| 人物/感知主体 | 行动依据或观看变化是否缺失 | 补行为/操作证据，无人物不补弧线 |
| 结构 | 连续段落是否重复同一功能 | 合并重复或改变信息，不机械加低谷 |
| 场景 | 输入/变化/输出能否相接 | 补桥接、重排；成功/恢复场不强加灾难 |
| 对白/声音 | 是否只解释已知事实 | 改语言行动、声源或反应 |
| 接口 | 分镜是否被迫猜能力/位置 | 澄清边界，不直接重写全部下游 |

## 旧稿迁移操作
将旧稿拆成“原句/动作—功能—依赖旧事实—当前等价实现—邻场风险”。优先迁移互动、升级、认知、决定与节奏，不搬名词。

### 完成小例（虚构版本条件）
当前事实：铜片只是指示器；手轮机械开闸；闸门仍完整，本场末才卡住。旧稿：角色召唤光花修复已碎闸门后独自离开。

| 旧功能 | 禁止带回 | 当前等价实现 | 回归检查 |
|---|---|---|---|
| 两人互不信任地合作 | 光花修复能力 | 一人照亮刻度，另一人转手轮，先争谁控制速度 | 铜片不发能量，双方位置可达 |
| 压力逐步升级 | 开场闸门已碎 | 手轮阻力增大，照明者发现刻度不再移动 | 卡住只发生一次且在既定时点 |
| 从反馈获得认识 | 角色突然全知 | 操作者停手核对刻度，再请同伴共同观察 | 先给可读反馈再决定 |
| 主动决定 | 不可用出口仍称主动放弃 | 核实仍可上服务梯后，选择留在手轮旁协作 | 通过选项表，不夸大成必死牺牲 |

完整表演草拟：照灯偏离→操作者误判→对方指出刻度→停手确认→交代协作方式→重新尝试→闸门卡住→决定后续行动。此链只是功能重建，须再写成现在时正文；不能以箭头清单冒充完成场景。

## 压缩与失败回退
先保留完整稿并标未实测估时，再删重复、合并同功能互动或缩小事件范围。若硬时长不容决定证据，交“保留证据但需延时/缩事件”的选项，不假报满足。当前事实缺失先请求/检索项目已授权材料，无法确定则标未决，不能用旧稿补 Canon。新增规则才可救场时，提案给世界阶段，等待裁决。

正式旧稿迁移任务的完成判据：有证据化诊断、功能迁移表、实际新正文及邻场回归结果；局部讨论只交本轮判断或试写，不扩成整套报告。未生成/未测试不写已验证，下游只列影响清单而不擅改。

## 反馈分类：先保护火花，再吸收最小有效修改

**触发/证据**：反复改结尾、多人意见冲突、用户说越改越不像自己时，取原始意图原话、当前稿位置、反馈原话及版本。分开阅读反应（感到冷漠）、理解障碍（不知为何返回）、偏好（更爱团圆）、改题建议（把悲剧改救赎）。一个意见可同时含反应和处方，须拆开：反应是真实经验，处方仍需判断；AI 模拟的“观众会”只是预期。

**选择**：对每项提出竞争解释：返回缺动机证据，还是读者不接受已建立的价值？沉默冷漠，还是用户要的克制？先对照不可替代的火花，再选最小吸收、保留、暂缓或拒绝。补动作提高可懂性但可能损失节制；加解释降低歧义但可能杀死怪异；改题可开启新版本但须用户授权，不能按多数票取代愿景。反馈合并时只更新受影响场、设定与未决项，保留否决理由；必要时请用户复述理解，不虚构试读结果。

**虚构例/反例**：用户要“她留下，却不承诺原谅”。读者不知道为何留下，可补她看见伤员无法站立后放下行李；“最后拥抱说原谅”改变主题，先拒绝或另列待选。若已锁出口却声称她主动放弃逃生，属真实选项错误，不能以“我想保留暧昧”免修。边界是愿景能保护未解释意义，不能保护因果漏洞或事实失实。来源：Wonderbook 阶段8；Bird by Bird Part Three 反馈章节，细分类为本套件转译。

## 反向提纲：从现稿事实而非旧计划回读

**启用**：正文偏离大纲、拼接多稿、结尾反复改动或结构表正确却读不顺。先取得当前稿及必要邻场；没有正文只能列待查问题，不拿原纲冒充反向提纲。

1. 暂把旧纲放旁边，逐场摘实际 POV、行动/操作、信息进入位置、可见后果、出口状态和后续使用；引用场号或原句。不要写作者“本想发生”的事。
2. 从事实归纳实际功能：关系建立、认知、节奏、规则、母题都可能有效；未写出的转变标缺证据，不替稿件脑补。
3. 再比旧纲，标有价值偏离、桥接缺口、重复功能、与已批准事实冲突。偏离不自动是错；关联新版与旧版时不把旧设定复活。
4. 并列可选处理：保留偏离并更新纲（保留新生命力，但需重审后续）、补最小桥接（低成本，但可能冗余）、重排/合并（提效率，但可能损失情感铺垫）、回到旧纲（只在当前偏离损伤承诺时，代价是舍弃新材料）。
5. 用户只要判断可停在建议；要求改写且输入足够即写受影响正文，再核相邻场输入输出与承诺，不要求全稿回滚。

**虚构小例**：旧纲是“争执→独逃→返回”，现稿却是“共同试修→一人受伤→另一人放下行李扶他”。反向结果应写“合作压力下选择继续照护”，不是“缺独逃场所以补逃跑”。若无伤情被察觉的证据，只补看见试站失败即可；保留偏离需调整后段关于‘曾抛弃同伴’的对白。反例是按旧纲给三场贴标签，实际正文没有逃跑仍记作逃跑。

**边界**：这是现稿诊断器，不是所有构思必须先做的工序。感知片用观看变化/操作后果替代欲望弧线。来源：Wonderbook §5.8；Bird by Bird §4.7。
