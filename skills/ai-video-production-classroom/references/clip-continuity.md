# 镜头、生产组、生成请求、剪辑单元与连续性

加载条件：导演镜头转请求、比较长短窗口、续接、补段或剪辑交接时加载。

## 1. 先建映射，再决定调用

1. 从分镜读取 shot_id、观看任务、机位、变化节点、导演目标时长和切点；不在生产层擅改动作/信息。
2. 先建立 production_group：按共同任务、空间、主体状态、连续动作链和参考集合组合镜头；Clip/DO 只作可选别名。详细算法见 `production-grouping-and-task-contract.md`。
3. 给每次计划调用独立 generation_request_id，记录覆盖 production_group/shot、状态链及平台窗口。一个镜头可以跨请求，一个请求可含多镜头或多组，但必须有平台能力依据。
4. 给后期片段独立 edit_unit_id；计划阶段记 planned in/out，结果到达且实际裁切后才填 actual。合成片段列出所有来源请求、轨道与时间范围，不用一个 Clip/DO ID 隐藏补段。
5. 分开导演目标、请求窗口、实际输出时长、实际采用时长。未生成不填实际值；窗口余量用于 handles 或动作闭合，不添加无功能行走。

## 2. 长短选择不是固定规则

| 条件证据 | 选择候选 | 验证与退出 |
|---|---|---|
| 长窗口受支持，空间/材料连续，跨段运动相位重要 | 长请求覆盖连续变化；多镜头仅在支持时纳入 | 检查漏节点、漂移、节奏；失败区间可局部补，不立刻废弃全片 |
| 窗口不足、复杂接触/状态变化多，或已有长段反复失败证据 | 在可观察状态边界拆短 | 检查连接身份、速度、位置、光色；短段也可能重建漂移 |
| 多镜头能力未知，仅有单镜证据 | 单镜或单变化能力试验 | 无证据不宣称多镜连续成功；预算不允许则等待核验 |
| 主体段已通过，只有接口不合格 | 桥接、局部补段或调整切点 | 切点不可掩盖要求必须可见的接触/结果证明 |
| 平台/窗口完全未知 | 平台中立映射及条件候选 | 留窗口 unknown，不伪造秒数上限或执行结果 |

比较长短时保护同一导演目标、起终态及完成判据，分别记录接缝风险、漏动作、漂移、可用素材和重试成本。拆短增加的接缝也属于质量成本。单轮“长好短坏”不是平台普遍规律。

## 3. 接口状态要能观察和重建

按起始→触发→路径/接触→反馈→结束写状态链。人物/实体运动按适用性补支撑面、重心、遮挡、左右方向；抽象色场只需形态、材质、范围和相位，不强加地面。

接口至少记录：空间锚点与相机朝向、主体位置/朝向/遮挡、结构/材质/光色、运动方向与阶段、需要保留的声音尾部、来源和检查范围。

- 真实尾帧：记录原片 ID/版本、时间码、提取文件、实际上传回执；观察合格才继承。单帧可检查形态，不足以验证速度，须连看邻近区间。
- 文字重建：明确标 `source: textual_reconstruction`，列已知状态与未知项；不可称像素级续接。
- 不合格接口：冻结下游，选择上游局部修复、稍早合格切点或授权桥接。坏尾帧不得因“已生成”继续传播。
- 无裁切/播放工具：交 EDL 式决策表和待核验清单，所有 in/out 为 planned；不声称完成导出或接缝通过。

## 4. 完整小例（仅为计划，不含真实平台能力声明）

object-led / perceptual，character:null。目标是固定镜头看金属环由倾斜回正、停止；另一个细节镜头观察停止后的材质。上游分镜给 SHOT-ring-wide 与 SHOT-ring-detail，不能把两个机位无声合并成同一导演镜头。

计划 A：若平台支持同一请求内受控换镜，REQ-ring-A 覆盖两镜；EDIT-ring-wide 和 EDIT-ring-detail 分别从该请求取片段，裁切范围待真实结果确认。

计划 B：若仅单镜有能力证据，REQ-ring-wide 生成回正至停止，REQ-ring-detail 从经观察合格的静止状态生成细节镜头。EDIT-ring-wide 来源前者、EDIT-ring-detail 来源后者；导演目标时长保留上游值，请求窗口待能力核验，actual in/out 均 null。

接口：环直立、底部接触台面、缺口朝画面上方、光从左上方来、运动已停止。计划 B 必须等待第一段的真实末段观察；若环仍摇摆，不能假填“已停止”。可延长原动作闭合或经导演同意在稳定区间切；不能靠删除停止判据伪称通过。

回归：复查环结构/缺口、接触、回正路径、停止证明、细节镜头朝向和接缝光色。若只细节失败，保留合格 wide 段和其批准证据；局部补后重审接口，不无故全片重生成。
