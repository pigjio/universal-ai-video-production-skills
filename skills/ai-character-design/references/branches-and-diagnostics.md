# 角色分支与诊断

## 混合生物：自然规律 → 结构 → 运动 → 剧情/感知功能

输入：必需动词、主识别物种、世界规则、允许的拟人程度。先收集可观察的自然行为；照片证明外形，连拍/视频才支持过程。每张参考写“提取什么/不提取什么”，不找现实中不存在的完整混合物种。

1. 把剧情动词转成物种行为，如人类指点改成视线切换、前爪拍触；先确认功能等效。
2. 分配来源职责：主动物负责第一识别、骨架与默认行为；次动物只补运动缺口；植物负责闭合、展开、朝光、散播等规律；器物/材料负责世界功能。少来源优先，额外系统必须证明必要性，不把固定配比当解剖约束。
3. 将规律画成结构连接：根部/关节/附着、连续体块、折叠顺序、受力通路。说明是毛束模拟花瓣、真实植物共生，还是纯隐含的开合规律，不能混写。
4. 做起始—中间—结束姿态，检查连接、体积、支撑、碰撞与回收。静态好看但中间过程不成立，先修连接或换动作，不靠变身闪光遮盖。
5. 反推功能：此结构让哪个行动、感知变化或剧情结果成立？删掉来源后若无任何损失，删去该来源。

具体判断示例：花苞闭合规律 → 胸前叠覆毛束及固定根部 → 受惊收紧、信任时展开 → 观众读到接近意愿。若展开会挡住前爪抱持，则减少肩侧体积或调整展开方向；不能为保留装饰删除已确认的抱持动作。无需信任弧线的感知短片，可把功能写成呼吸般的开合节奏，不补人物创伤。

## 系列 DNA 的观察与校准

1. 读取最新已确认母版及裁决，观察头脸简化、视觉头身关系、手脚尺度、圆角/尖角、关节概括、服装分割、色彩面积、边缘与材质。标注图中可见事实；透视遮挡无法测出的比例保持未知。
2. 建“共享语法/主角专属”两栏。共享造型语法，不共享主角全部发型、道具和主色组合。旧文本与图冲突时记录并请求裁决，不擅自用旧数字反改母版。
3. 从世界功能或生态位推导变量：体型、姿态、大色块、劳动磨损；职业标签不是视觉证据，也不能凭空发明阶层历史。
4. 先做母版主体 + 标准成员 + 关键变体的校准板（数量可按项目缩减），同基线、同照明、相同观看尺度。先去色/去服装看是否同系列，再加回专属识别看是否能区分。
5. 校准通过才扩群；背景成员可共享结构，近景成员按镜头需求补表情。失败若“像多个项目”，回共享语法；若“主角换色复制”，回变量矩阵，不加随机饰品。

示例记录：共享“圆角方形躯干、低细节鼻口、哑光面”；专属“主角破边帽与斜背工具”。居民以直立姿态和横向装载体积区分，不复制帽子。没有校准图时交校准计划，不能写已通过。

## 有益意外：保留偶然性，只修功能断点

先隔离新候选，不覆盖旧母版。逐项问：第一识别是否更好？必需功能是否仍在？结构是否连续？动作/转面能否实现？核心记忆点是否被挤掉？世界规则是否冲突？

- 功能、结构均成立：保留候选，做关键动作测试，再交人工裁决。
- 整体有生命力、局部功能断点：冻结有效脸/比例/色彩，仅修断点。
- 只有漂亮但改变必需动作/世界规则：回旧母版或申请上游变更，不用结果反写剧情。
- 缺中间态证据：标待验证，不提前生产批准。

双重读取示例：静止像闭合花苞，伸展时显露刷状接触面；两态共享根部、毛流和体积，不临时新增零件。若无法连续转化，则改连接或放弃第二读取。

## AI 漂移故障树与资产分支

身份漂移 → 先核对实际输入是否为当前母版 → 否：修输入；是：检查参考职责/提交装配/工具能力 → 有冲突：删越权参考；无冲突：用同视角简单单变量复测 → 简测仍漂移才回 Face ID/体块，不默认重画全角色。

多状态：共同身份不变，分别记录触发、变项、禁变项、回归条件和稳定 ID。固定卡：指定唯一造型母版与各模块权威层级；已通过素材用确定性拼版，保留关键轮廓，不用生成模型重画来假装像素锁定。没有合成工具时交布局与素材清单，不称已导出。

## 群像关系动作

**触发/证据**：角色单看有特点、合起来却像排队；用户要保护、试探、疏离等关系感。读取已知剧本关系、同一刺激、各自压力策略、核心动作能力和道具接触；关系未知先比较条件方案，不自立剧情事实。观察资料可记录视线、手势、距离与道具使用，不由姿态臆断真实人的身份/心理。

**判断链**：同一刺激 → 每人想达成什么、采取什么策略 → 关系动词（保护、忽视、模仿、安慰、协商等）→ 视线目标、身体朝向、距离、高低和接触 → 双人无脸姿态 → 交换两人策略作反证 → 回查单体结构和动作身份能否完成。若互换仍没有任何关系变化，可能只做了身高差；也可能当前场面本就要求一致行动，不强行制造冲突。

**例子/可选处理与代价**：同伴听到门后异响，A 保护 B，身体侧转留出观察缝、前臂挡在 B 前方却不推开他；B 胆小但仍想协助，脚留退路、头探过 A 肩侧、手把工具递向 A。方案一距离近、接触多，互助易读但轮廓容易粘；方案二拉开半步并通过递工具连接，剪影清楚却可能读成疏离，需保留相互视线。距离只作草案相对关系，不偷定场景尺寸或最终机位。

**反例/修复**：两人仅同向惊讶、并肩站直，可能读出共同刺激而非“保护”；先改朝向/接触，不先换脸。若已知关系是互不信任，不能擅自塞入亲密搭肩。双人姿态成立但衣袖阻止抬臂，就回单体服装/关节需求，不通过修改剧本动作迁就装饰。

**边界**：讨论可交一组文字姿态及易混读法，不索要完整 lineup/母版。生产扩群仍用上文共享/专属校准；此处给角色表演能力与关系候选，最终镜头调度、轴线、空间和节奏交分镜。无真实图或观众反馈不称关系测试通过。
