# 表演与生产验证

角色是核心动词、压力反应和运动身份，不只是外貌。按任务验证默认、压力、行动、社交、失败姿态；非叙事角色可把不适用项替换为感知变化和运动状态。表情由眼眉口、颈肩、重心和手势共同完成。

## 四层闸门与可执行测试

| 层 | 输入与步骤 | 通过依据 | 失败回退 |
|---|---|---|---|
| A 概念 | 同尺度剪影并排；不展示角色说明，询问第一感觉与识别依据 | 关键识别与项目目标一致；无禁止项 | 主形、负形、内核 |
| B 结构 | 当前母版、测量姿态和端点；正侧背/四分之三按同标尺叠网格；测试极端姿态 | 主体体积、连接、非对称项闭合；偏差在预先约定容差内 | 标尺/体块，不先调材质 |
| C 表演 | neutral 起步；核心表情及易混淆对；遮脸看动词；看重心、手与道具接触 | 关键情绪能被观察者区分，动作身份不丢 | 表情意图→头骨/姿态→绑定需求 |
| D 下游 | 在目标镜头尺度、背景与光照下试读；列关节范围、模拟、挂点、LOD 和交接 | 所需分支均有证据，未验证项明确并不冒称完成 | 对应模块最小回退 |

先确认本次是概念、AI 图像/视频还是传统 3D 生产。未做实际 rig 测试只能交绑定需求与风险，不写“绑定通过”。表情数量不等于表现力；关键表情的误读必须单独阻断，不能被总体命中率掩盖。

## 表情与动作测试步骤

1. 区分结构静止位、习惯脸与即时变化；探索可暂定头骨、眼位、口轮和颈肩关系，正式派生才锁来源。先做当前目标差量，再按需要增加强度。
2. 用“惊讶/恐惧”“疲惫/悲伤”“坚定/愤怒”等与本项目有关的易混淆对盲测；记录观察原话、图 ID、显示尺度与是否看过情节。
3. 如果静态无法辨认认知过程，补视线—呼吸—姿态的连续草图，不强求单张脸说明全部心理。
4. 生成脸漂移先减少表情组和参考冲突，再修头骨；动作像人偶先修领先部位、动态线、重心和接触，不先加夸张嘴型。
5. 将新姿态放回相邻动作检查，确认道具从携带到使用再收纳都有可解释路径。

规范示例：目标“担忧但决定继续”，观察者读为愤怒；保留锁定脸型，降低眉压、保留紧握动作，增加后退重心向前移的过程。下一轮仍需盲测，不能把修订文字当通过证据。

## 故障树

- 静止就不像？→核对母版/版本→剪影失败回 A；只有转面失败回 B。
- 静止像、运动不像？→检查体积与关节→若结构正确再查动作线/重心/相位→最后查工具执行，不整体换脸。
- 表情误读？→意图是否明确→脸与身体冲突是有意遮掩还是失误→三层基线是否分清→局部眉眼口控制；不要直接要求更多表情或抹除有意冲突。
- 衣物遮动作？→先剪裁/挂点/碰撞空间→再比较简化或模拟方案；没有真实模拟证据写风险。
- 只在远景丢失？→减少微细节依赖、加强大块对比→与场景协作测试，不把角色全身提亮作为唯一办法。

## 完整 Force 路径

**触发/证据**：姿态像人偶、动作有弧线却无重量、附件不跟身。读取动作意图、前后姿态、接触物/身体机制与当前动作相位；缺连续图时可画文字受力草案，不能称力学验证。

**判断链**：动词与态度 → 力从何处进入（推地、手拉绳、外物撞击等）→ 主要承接/峰值体块 → 力向何处释放 → 当前/前后锚点 → 头胸盆角度与四肢响应 → 服装、道具的跟随、滞后或对抗 → 能否从前姿态进入并退出到后姿态。入口、峰值、出口是视觉组织标记，不是数值应力计算。

**竞争解释/处理**：僵硬可能是主力方向不明、身体所有部分同相位、附件无重量，也可能是角色故意僵住。先明确哪一种：可强化躯干领先、让次部位滞后或补接触转换；故意僵住时只保留微小呼吸/视线差量，不强塞大 S 曲线。静态承重查支撑面；动态奔跑、腾空、失足检查惯性与接触转换，无当前地面锚点可以成立，必须说明此前发力与接下来接触，而不是把脚硬拉回重心下。

**例子/代价**：拉开卡住的门：握把为外部接触，脚与地面给反向锚定，背/骨盆承接张力，门松开后身体后退、手臂延展、衣摆滞后。强化后仰更显吃力，但太大可能读成即将摔倒；可保留前脚制动。跃沟则从后脚推地到躯干前送、腾空、前脚落地吸收；中途重心在支撑区外不是错误。

**反例/边界**：为“稳定”把跳跃帧改成双脚站地，消除了动作；用漂亮曲线掩盖手离开门把，也不能证明拉门。超现实身体按作品机制解释连续性，不强加人体规则。讨论止于可用姿态/风险，生产才需要真实运动或 rig 证据。

来源：Force「模块4 Force」。

## 三层表情基线

**触发/证据**：“这人不笑也严厉”“一做 neutral 就不像”“是困倦还是悲伤”。读取无即时刺激时的头脸、习惯姿态与当前情境，分层记眼睑覆盖、眉角、嘴角静止位、永久皱纹和活动皱纹；单张照片不足以判定习惯。

**判断链**：结构静止位（骨相、软组织和永久纹理）→ 习惯脸（反复出现的轻微眉压、口角、颈姿等角色偏置）→ 即时表情（相对此基线的变化与恢复残留）。工程 neutral mesh 是建模/绑定基准，角色 resting pose 是表演基线，二者可以不同但映射要明确。不要为了“中性”消灭角色特征，也不要把习惯偏置重复叠加成每场愤怒。

**竞争解释/取舍**：低眉可能来自骨相、习惯审视、当前愤怒、专注用力或顶光阴影。先比其他场景/灯光和身体行动，再决定保留结构、减少习惯偏置、改即时差量或调整展示光；直接改眉骨虽快速“变友善”，却可能换身份。证据不足则并列解释，不诊断心理。

**例子/反例**：严厉修理工的深眼窝保留；默认略压眉作习惯层；遇到坏消息，仅增加内眉变化、停手和口部收紧。若把永久眼袋当作悲伤每次加深，疲惫会被误写成情绪；若每个 neutral 都抬眉微笑，又会洗掉角色基线。局部讨论可只给这一次差量，不要求全表情表。

来源：Expression「模块1 neutral baseline」；Caricature「阶段7 3D 建模/绑定交接」的保留 default expression 建议。

## 复合与压抑表情

**触发/证据**：礼貌微笑但压抑委屈、忍笑、掩怒，或用户要求更微妙而非更强。先读真实情绪、对谁隐藏什么、希望对方怎样回应、镜头尺度与角色基线；未知社交关系用可替换假设，不擅定关系。

**判断链**：内部情绪 → 社交呈现目标 → 主次信息 → 眉眼、眼颊、口部、头颈/手各自职责 → 最小可见线索 → 强度与持续/恢复过程 → 比较易混读法。分区不是把两张表情平均相加，面部有意冲突可以正是表演目标。身体支撑整体社交意图，不要求所有区域表达同一种情绪。

**具体试写/代价**：假设角色不想让同伴担心，“礼貌微笑却委屈”可保留小幅、受控上提的嘴角，内眉轻抬并略收紧、下睑轻绷，目光短暂接住对方又移开，笑意在对方转身后缓慢退去。特写侧重口部控制与眉眼差量；中景可加保持端正却把手收回身体的动作；远景不靠微小内眉，改用回应的停顿、身体朝向或请求分镜给更近尺度。更强眉拧/唇压读得快，却可能变成忍哭；明显侧笑与低眉可能转成讥讽；过松眼睑可能读成疲惫。

**替代/反例**：若目标是“忍笑”，可让眼颊笑意泄露、口部压住，而非沿用悲伤眉；掩怒可上脸留张力、下脸礼貌控制，但先排除用力/疼痛/专注的身体解释。仅把悲伤脸和笑脸平均，会抹掉各区职责；一律要求眼口情绪统一也会破坏遮掩。眼颊参与不等于真实快乐，眼颊不动不证明撒谎，这不是测谎术，也不推断现实人物心理。

**核查边界**：有真实观察者才记录原话、图 ID、尺度及有无语境，比较委屈/讥讽/疲惫等读法；只有 AI 时明确为预期，不能填盲测通过。单张不能承载全部隐藏动机时给前后差量，不强制新增完整生产测试来回答讨论。

来源：Expression「模块8 基础表情」「模块9 强度阶梯」「模块10 复合表情」「模块11 语境、姿态、灯光」「模块12 身体状态表情」。
