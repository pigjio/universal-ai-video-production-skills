# 角色概念设计

先读取 [使用约定](references/usage-rules.md)。

以当前剧本中的身份、行为和用户偏好约束角色外形；只做所选角色或明确要求的范围。先讨论可见的造型差异，不把所有设计推理塞进提示词。

保留已确定的体型、面部识别点、服装和必要道具。非人角色按其身体特征描述，不强加人脸。无角色作品跳过本阶段。

## Midjourney 默认输出

提示词精简为四个短段落，通常每段一至两句；每项写具体特征，不堆砌抽象形容词：

1. 身份、体型比例与整体轮廓。
2. 脸型／下颌、眉眼、鼻嘴、发型等主要面部特征。
3. 服装、必要道具与姿态。
4. 配色、视觉重点、构图／背景／光线，以及用户已确认的风格。

没有风格要求时使用中性的“角色概念设计”。不要默认添加 3D、3D 动画、渲染风格，也不要擅自改成 2D 或写实；用户当前明确排除的风格优先。

不自动添加伤疤、装饰、全身、三视图、固定角度或白／灰背景；仅按本次用途和用户选择写。面部描述保持简洁但不可省略成“精致五官”。全身图无法保证所有面部细节可读，必要时另提近景选项。

给出独立可复制的文本块；设计说明放在块外。真实参考素材按实际用途说明，不编造上传句柄。静态图提示词不添加时间轴、声音或“无背景音乐”。

生成图未实际返回前只称概念或提示词草案，不保证身份一致性或建模／绑定可用性。
