# 授权 / 동의

未明确同意的操作不得执行。研究使用默认未同意。
명확히 동의하지 않은 작업은 실행하지 않습니다. 연구 활용은 기본적으로 동의하지 않은 상태입니다.

| 操作 / 작업 | 状态 / 상태 | 范围 / 범위 | 用户明确依据 / 동의 근거 |
|---|---|---|---|
| 保存 / 저장 | 未授权 / 미동의 | | |
| 覆盖删除 / 덮어쓰기·삭제 | 未授权 / 미동의 | | |
| 上传 / 업로드 | 未授权 / 미동의 | | |
| 生成与费用 / 생성·비용 | 未授权 / 미동의 | | |
| 发布 / 공개 | 未授权 / 미동의 | | |
| 研究使用 / 연구 활용 | 未同意 / 미동의 | | |

用户可撤销同意；保存不代表其他授权。사용자는 동의를 철회할 수 있으며 저장 동의는 다른 작업의 동의가 아닙니다.
